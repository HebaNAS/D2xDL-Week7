One example with x = 1, so z = w and ∇w = ∂l/∂z. Squared loss keeps the sigmoid slope Ŷ(1 − Ŷ), which is ≈ 0 near Ŷ = 0 or 1. Log loss cancels it, so its gradient −δ stays large while Ŷ is wrong.
