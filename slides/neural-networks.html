Neural Networks:

Multi-layer Perceptrons

Recap: Perceptron

  • Perceptron: single neuron
  • Receives input from D-many neurons
  • Each input has a weight
  • Cell sums up weighted input
  • Neuron “fires” if sum > 0

Neural Networks: Multi-layer Perceptrons

  • We can think of neural networks as combination of multiple perceptrons
    • Multilayer perceptron (MLP)
  • Why would we want to do that?
    • Discover more complex (a.k.a. non-linear) decision boundaries
    • Learn combinations of features

Let’s design a 2-layer MLP

  • Layer-2: \(\hat{y} = g(\mathbf{v} \cdot \mathbf{h})\)
  • Layer-1: \(h_i = f(\mathbf{w}_i \cdot \mathbf{x})\)
  • \(f, g\) are called activation/link functions
    • hyperbolic tangent (\(\tanh\))
    • Sigmoid \(\sigma(x) = \frac{1}{e^{-x} + 1}\)
    • Rectified Linear Unit (ReLU)
    • Identity (usually not in Layer-1)
  • Set \(f = \tanh,\ g = \mathit{identity}\)
  • \(\hat{y} = \sum_i v_i \tanh(\mathbf{w}_i \cdot \mathbf{x}) = \mathbf{v} \cdot \tanh(\mathbf{W} \cdot \mathbf{x})\)

Activation Functions

  • Activation functions are usually non-linear functions
  • Surrogates to non-linear as in the perceptron
  • BUT they are differentiable!
    • hyperbolic tangent \([-1, 1]\)
    • Sigmoid \([0, 1]\)
The green “non-linear” is the perceptron’s sign function (green in the plot): it has no useful gradient, so we replace it with a smooth surrogate. tanh is a stretched sigmoid: tanh(a) = 2σ(2a) − 1.

Solving XOR by Hand

Two tanh hidden units and an identity output, with hand-picked weights:

Hidden unit 1 \(\approx\) OR: \[ h_1 = \tanh(5x_1 + 5x_2 + 5) \]
Hidden unit 2 \(\approx\) AND: \[ h_2 = \tanh(5x_1 + 5x_2 - 5) \]
Output, “OR and not AND”: \[ \hat{y} = h_1 - h_2 - 1, \quad \text{predict } \mathrm{sign}(\hat{y}) \]
\(x_1\)\(x_2\)\(h_1\)\(h_2\)\(\hat{y}\)target
−1−1−1.00−1.00−1.00−1
−1+1+1.00−1.00+1.00+1
+1−1+1.00−1.00+1.00+1

\(\tanh(5) = 0.9999\), so each hidden unit is almost a ±1 switch.

Each hidden unit is one line, like a perceptron. The output unit combines the two lines.

How the Hidden Layer Solves XOR

A sequence that works: 1) “Solved: OR and not AND” shows the weights from the last slide. 2) Drag a hidden-unit slider and watch its line move on the left and the points move on the right. 3) “Random start”, then Play: training finds its own solution. 4) Untick “Use biases”: (1,1) and (−1,−1) are forced to opposite sides, so one is always wrong. 5) Switch the hidden activation to identity: hidden space becomes a stretched copy of input space, and XOR stays unsolved.

Function Approximation with Neural Networks

  • Problem formulation
    • Set of possible instances \(X\)
      • Each instance \(\mathbf{x} \in X\) is a feature vector \(\mathbf{x} = [x_1, \ldots, x_D]\)
    • Unknown target function \(f: X \rightarrow Y\)
      • \(Y\) is binary valued \(\{-1, +1\}\)
    • Set of function hypotheses \(H = \{h \mid h: X \rightarrow Y\}\)
      • ???
  • Input
    • Training examples \(\{(\mathbf{x}^{(1)}, y^{(1)}), \ldots, (\mathbf{x}^{(N)}, y^{(N)})\}\) of unknown target function \(f\)
  • Output
    • Hypothesis \(h \in H\) that best approximates function \(f\)
Ask: what is H for a neural network? Every function the network can compute with this architecture, one function for each setting of the weights W and v. The next slide says how big that set is.

Two-Layer Networks are Universal Function Approximators

Theorem: Let \(F\) be a continuous function on a bounded subset of \(D\)-dimensional space. Then there exists a two-layer neural network \(\hat{F}\) with a finite number of hidden units that approximates \(F\) arbitrarily well. Namely, for all \(\mathbf{x}\) in the domain of \(F\), \[ |F(\mathbf{x}) - \hat{F}(\mathbf{x})| < \epsilon \]

… or put simply, two-layer networks can approximate any function!

The theorem says such a network exists. It does not say how many hidden units we need, or that gradient descent will find the weights.

Design Question

  • How many hidden units? How many layers?
    • Inductive bias / Regularisation
    • More hidden units yield more complex functions
      • Overfitting
    • Fewer hidden units requires fewer examples to train

Training Neural Networks:

Backpropagation

Training Neural Networks

Backpropagation algorithm =

Gradient descent + Chain rule

  • Forward: compute \(\mathbf{h}\) and \(\hat{y}\), layer by layer
  • Backward: pass the error back down, layer by layer (the arrows), to get every weight’s gradient

What’s our training objective?

  • We will consider the following objective \[ \min_{\mathbf{W}, \mathbf{v}} L(\mathbf{W}, \mathbf{v}) = \min_{\mathbf{W}, \mathbf{v}} \sum_n \frac{1}{2} \Big( y_n - \sum_i v_i \cdot f(\mathbf{w}_i \cdot \mathbf{x}_n) \Big)^2 \quad \text{where} \quad \hat{y}_n = \sum_i v_i \cdot f(\mathbf{w}_i \cdot \mathbf{x}_n) \]
    • i.e., our goal is to find parameters \(\mathbf{W}, \mathbf{v}\) that minimise squared error
    • \(N\) examples with \(\mathbf{x}_n, y_n\)
  • Other objectives are possible (exponential, logistic, etc.)
  • Weight regularisation

Recap: General Gradient Descent Algorithm

Algorithm: GRADIENT DESCENT(\(L(\mathbf{w}, b; \mathbf{D}), \mathbf{D}, maxIter, \eta_1, \ldots, \eta_k\))
  1. \(\mathbf{w}^{(0)} \leftarrow \langle 0, 0, \ldots, 0 \rangle,\ b^{(0)} \leftarrow 0\)// initialise the weights vector and bias
  2. for \(k = 1 \ldots maxIter\) do
  3. \(\mathbf{g}^{(k)} \leftarrow \nabla_{\mathbf{w}, b} L(\mathbf{w}, b; \mathbf{D})\big|_{\mathbf{w}, b^{(k-1)}}\)// gradient (slope of the loss) at the current point
  4. \(\mathbf{w}^{(k)} \leftarrow \mathbf{w}^{(k-1)} - \eta^{(k)} \mathbf{g}^{(k)}\)// step down the gradient
  5. \(b^{(k)} \leftarrow b^{(k-1)} - \eta^{(k)} \frac{\partial L}{\partial b}\)// update the bias the same way
  6. end for
  7. return \(\mathbf{w}^{(k)}, b^{(k)}\)
Greek letters
\(\eta\) (eta): learning rate, the step size
\(\nabla\) (nabla): gradient, the vector of partial derivatives
\(\partial\): partial derivative
Notation
\(\mathbf{w}^{(k)}\): value of \(\mathbf{w}\) at iteration \(k\)
\(\langle 0, \ldots, 0 \rangle\): vector of zeros
\(\leftarrow\): assignment
\(\big|_{\mathbf{w}, b^{(k-1)}}\): evaluated at the previous values
Variables
\(\mathbf{w}, b\): weights and bias we optimise
\(L\): loss, the prediction error
\(\mathbf{D}\): the training data
\(\mathbf{g}\): gradient, the update direction
\(k\): iteration number
The only new part for a network: line 3 needs the gradient for every weight, in both layers. Backprop is how we compute it.

Backprop Toolbox: Five Facts

The next slides use only these. Keep them in view while we derive the gradients.

1 · Chain rule If \(L\) depends on \(w\) only through \(u\): \(\quad \dfrac{\partial L}{\partial w} = \dfrac{\partial L}{\partial u} \cdot \dfrac{\partial u}{\partial w}\) Used at every step: follow the path from the weight to the loss
2 · Squared error \(L = \frac{1}{2} e^2,\ e = y - \hat{y} \ \Rightarrow\ \dfrac{\partial L}{\partial \hat{y}} = -e\) The start of both gradients
3 · Weighted sum \(g = \sum_i v_i h_i \ \Rightarrow\ \dfrac{\partial g}{\partial v_i} = h_i,\ \ \dfrac{\partial g}{\partial h_i} = v_i\) Output weights, and passing the error back to \(h_i\)
4 · Dot product \(\dfrac{\partial (\mathbf{w}_i \cdot \mathbf{x})}{\partial \mathbf{w}_i} = \mathbf{x}\) Hidden weights (as in linear regression)
5 · tanh \(\tanh'(a) = 1 - \tanh^2(a)\) Going through the hidden activation
Copy these five onto the whiteboard (B) in a corner, then come back (B again) and point to each one when it is used. Most students who get lost in a derivation are missing one of these facts, not the logic.

Two-layer NN: Gradient of output layer weights \(\mathbf{v}\) (1/3)

Where we’re heading\(\nabla_{\mathbf{v}} = -e_n \cdot \mathbf{h}_n\)line 13 of the backprop algorithm: \(\mathbf{g} \leftarrow \mathbf{g} - e\,\mathbf{h}\)

The loss function: \[ L(\mathbf{W}, \mathbf{v}) = \sum_n \frac{1}{2} \Big( y_n - \sum_i v_i \cdot f(\mathbf{w}_i \cdot \mathbf{x}_n) \Big)^2 \]

Breaking this down, for each training example \(n\):

  • the prediction: \(\hat{y}_n = \sum_i v_i \cdot f(\mathbf{w}_i \cdot \mathbf{x}_n)\)
  • the error: \(e_n = y_n - \hat{y}_n\)
  • the loss: \(L = \frac{1}{2} e_n^2\)

We want: how does the loss change when we change the output weight \(v_i\)? That is \(\dfrac{\partial L}{\partial v_i}\).

Say the destination first: by the end of three slides we will have line 13 of the algorithm. The output layer is the easy one: v only touches the loss through ŷ.

Two-layer NN: Gradient of output layer weights \(\mathbf{v}\) (2/3)

We use \(g\) for the network output (the prediction). By the chain rule (fact 1): \[ \frac{\partial L}{\partial v_i} = \color{#3274B5}{\frac{\partial L}{\partial g}} \cdot \color{#A62B17}{\frac{\partial g}{\partial v_i}} \]

Part 1: how does the loss change with the prediction?

\(L = \frac{1}{2}(y_n - g)^2 = \frac{1}{2} e_n^2\)
\(\displaystyle \frac{\partial L}{\partial g} = \frac{\partial L}{\partial e} \cdot \frac{\partial e}{\partial g} = (y_n - g) \cdot (-1)\)
chain rule again: \(e = y_n - g\), so \(\partial e / \partial g = -1\)
\(\color{#3274B5}{\displaystyle \frac{\partial L}{\partial g} = -e_n}\)
fact 2

Part 2: how does the prediction change with \(v_i\)?

\(g = \mathit{identity}\Big(\sum_i v_i \cdot h_{i,n}\Big)\)
\(\phantom{g} = v_1 h_{1,n} + v_2 h_{2,n} + \ldots + v_K h_{K,n}\)
identity output: \(g\) is just the weighted sum
\(\color{#A62B17}{\displaystyle \frac{\partial g}{\partial v_i} = h_{i,n}}\)
fact 3: only the \(v_i h_{i,n}\) term contains \(v_i\). The prediction changes by exactly \(h_{i,n}\) when \(v_i\) changes by 1.
Before each click, ask for the next line. Part 2 is the one to ask about: “which terms of the sum contain v_i?”

Two-layer NN: Gradient of output layer weights \(\mathbf{v}\) (3/3)

Putting it together:

\[ \frac{\partial L}{\partial v_i} = \color{#3274B5}{-e_n} \cdot \color{#A62B17}{h_{i,n}} \]

In vector form, with \(\mathbf{h}_n = [h_{1,n}, h_{2,n}, \ldots]\) the hidden activations for example \(n\):

\[ \nabla_{\mathbf{v}} = -e_n \cdot \mathbf{h}_n \]

The update rule*:

For a single example (online): \(\ \nabla_{\mathbf{v}} = -e_n \cdot \mathbf{h}_n\)

For all examples (batch): \(\ \nabla_{\mathbf{v}} = -\sum_n e_n \cdot \mathbf{h}_n\)

\[ \mathbf{v} \leftarrow \mathbf{v} - \eta \cdot \nabla_{\mathbf{v}} \]

* Assuming a linear (identity) activation at the output unit, \(g = \mathit{identity}(\sum_i v_i \cdot h_{i,n})\)

Compare with linear regression in Lecture 1: \(\mathbf{w} \leftarrow \mathbf{w} + \eta \cdot \delta \cdot \mathbf{x}_n\). The output layer is linear regression on the hidden features \(\mathbf{h}_n\) instead of the inputs \(\mathbf{x}_n\).
Point back to line 13 (g ← g − e h) and line 19 (v ← v − η g) of the backprop algorithm. The minus signs cancel: v − η(−e h) = v + η e h, which is the Lecture 1 update with h in place of x.

Quick Check: Output Weights

One minute with your neighbour, then we compare answers.

1The network predicts example \(n\) perfectly. How much does \(\mathbf{v}\) change on this example?
Not at all. \(e_n = 0\), so \(\nabla_{\mathbf{v}} = -e_n \mathbf{h}_n = \mathbf{0}\). Gradient descent only learns from errors.
2Hidden unit \(i\) outputs \(h_i = 0\) for every example. What happens to its outgoing weight \(v_i\)?
It never changes. Its gradient is \(-e_n h_{i,n} = 0\): a unit that says nothing gives \(v_i\) nothing to learn from.
Give a minute, take two or three answers, then click to show each answer.

Two-layer NN: Gradient of hidden unit weights \(\mathbf{w}_i\) (1/4)

Where we’re heading\(\nabla_{\mathbf{w}_i} = -e\, v_i \big(1 - \tanh^2(a_i)\big)\, \mathbf{x}\)line 15 of the backprop algorithm

The loss function (one example): \[ L(\mathbf{W}, \mathbf{v}) = \frac{1}{2} \Big( y - \sum_i v_i \cdot f(\mathbf{w}_i \cdot \mathbf{x}) \Big)^2 = \frac{1}{2} e^2 \] where the error is \(e = y - \sum_i v_i \cdot f(\mathbf{w}_i \cdot \mathbf{x})\).

The chain rule: \[ \frac{\partial L}{\partial \mathbf{w}_i} = \color{#3274B5}{\frac{\partial L}{\partial f_i}} \cdot \color{#A62B17}{\frac{\partial f_i}{\partial \mathbf{w}_i}} \]

In simple words: \(\mathbf{w}_i\) only reaches the loss through the activation \(f_i\) of hidden unit \(h_i\), so we go through it.

The destination again: line 15. It looks long, but it is three factors we already know times x. Ask: what is the path from w_i to the loss? w_i → a_i → h_i → ŷ → L.

Two-layer NN: Gradient of hidden unit weights \(\mathbf{w}_i\) (2/4)

\[ \frac{\partial L}{\partial \mathbf{w}_i} = \color{#3274B5}{\frac{\partial L}{\partial f_i}} \cdot \frac{\partial f_i}{\partial \mathbf{w}_i} \]

Part 1: how does the loss change with the activation of hidden unit \(i\)?

Let \(g = \sum_i v_i \cdot f_i\), so \(L = \frac{1}{2}(y - g)^2\).

\(\displaystyle \frac{\partial L}{\partial f_i} = \frac{\partial L}{\partial g} \cdot \frac{\partial g}{\partial f_i}\)
chain rule: \(f_i\) reaches the loss through the output \(g\)
\(\displaystyle \frac{\partial L}{\partial g} = -e\)
from the output layer slides (fact 2)
\(g = v_1 f_1 + v_2 f_2 + \ldots + v_K f_K \ \Rightarrow\ \displaystyle \frac{\partial g}{\partial f_i} = v_i\)
fact 3, the other way round
\(\color{#3274B5}{\displaystyle \frac{\partial L}{\partial f_i} = -e \cdot v_i}\)
the output error, sent back to unit \(i\) and scaled by its outgoing weight
This is the “back” in backpropagation: the error e at the output is passed back to each hidden unit, weighted by v_i.

Two-layer NN: Gradient of hidden unit weights \(\mathbf{w}_i\) (3/4)

\[ \frac{\partial L}{\partial \mathbf{w}_i} = \frac{\partial L}{\partial f_i} \cdot \color{#A62B17}{\frac{\partial f_i}{\partial \mathbf{w}_i}} \]

Part 2: how does the activation \(f_i\) change with the weights \(\mathbf{w}_i\)?

\(\displaystyle \frac{\partial f_i}{\partial \mathbf{w}_i} = \frac{\partial f(\mathbf{w}_i \cdot \mathbf{x})}{\partial \mathbf{w}_i} = f'(\mathbf{w}_i \cdot \mathbf{x}) \cdot \frac{\partial (\mathbf{w}_i \cdot \mathbf{x})}{\partial \mathbf{w}_i}\)
chain rule: outer function \(f\), inner function \(\mathbf{w}_i \cdot \mathbf{x}\)
\(\color{#A62B17}{\displaystyle \frac{\partial f_i}{\partial \mathbf{w}_i} = f'(\mathbf{w}_i \cdot \mathbf{x})\, \mathbf{x}}\)
fact 4: the inner derivative is \(\mathbf{x}\)
Ask which fact gives the x. It is the same x that appears in the linear regression gradient.

Two-layer NN: Gradient of hidden unit weights \(\mathbf{w}_i\) (4/4)

Putting it together:

\[ \nabla_{\mathbf{w}_i} = \color{#3274B5}{-e\, v_i} \cdot \color{#A62B17}{f'(\mathbf{w}_i \cdot \mathbf{x})\, \mathbf{x}} \]

For tanh, the gradient \(f'\) is (fact 5): \(\quad f'(\mathbf{w}_i \cdot \mathbf{x}) = 1 - \tanh^2(\mathbf{w}_i \cdot \mathbf{x})\)

With \(a_i = \mathbf{w}_i \cdot \mathbf{x}\) (line 8 of the algorithm) and \(h_i = \tanh(a_i)\) (line 9):

\[ \nabla_{\mathbf{w}_i} = \underbrace{-e}_{\text{error}} \cdot \underbrace{v_i}_{\text{how much the output uses } h_i} \cdot \underbrace{\big(1 - \tanh^2(a_i)\big)}_{\text{slope of } h_i\text{, also } 1 - h_i^2} \cdot \underbrace{\mathbf{x}}_{\text{input}} \]
Note on notation: a_i is the weighted input w_i·x (line 8), and h_i = tanh(a_i) is the activation. So 1 − tanh²(a_i) = 1 − h_i², which is how the code computes it. Read the four factors aloud; the next slide is the intuition for each.

Two-layer NN: Gradient of hidden unit weights \(\mathbf{w}_i\)

  • Intuition
    • Small \(e\) \(\rightarrow\) small gradient
    • \(v_i\) small \(\rightarrow\) output not sensitive to activation of \(h_i\) \(\rightarrow\) small gradient
    • \(v_i\) flips sign \(\rightarrow\) gradient should also flip sign

Quick Check: Hidden Weights

One minute with your neighbour, then we compare answers.

1A hidden unit has \(a_i = 5\), so \(h_i = \tanh(5) \approx 1\). How much do its weights \(\mathbf{w}_i\) move?
Almost not at all. \(1 - \tanh^2(5) \approx 0.0002\). A saturated unit learns very slowly, the same problem as the sigmoid with the squared loss in Lecture 1.
2We start with every weight in \(\mathbf{W}\) and \(\mathbf{v}\) equal to 0. What do the gradients look like?
Nothing can move. \(\mathbf{h} = \tanh(\mathbf{0}) = \mathbf{0}\), so \(\nabla_{\mathbf{v}} = -e\,\mathbf{h} = \mathbf{0}\); and \(v_i = 0\), so \(\nabla_{\mathbf{w}_i} = \mathbf{0}\). That is why we start from small random values.

Backprop for 2-layer Network

Algorithm 25 TWO LAYER NETWORK TRAIN(\(\mathbf{D}, \eta, K, MaxIter\))
  1. \(\mathbf{W} \leftarrow D \times K\) matrix of small random values// initialise input layer weights
  2. \(\mathbf{v} \leftarrow K\)-vector of small random values// initialise output layer weights
  3. for \(iter = 1 \ldots MaxIter\) do
  4. \(\mathbf{G} \leftarrow D \times K\) matrix of zeros// initialise input layer gradient
  5. \(\mathbf{g} \leftarrow K\)-vector of zeros// initialise output layer gradient
  6. for all \((\mathbf{x}, y) \in \mathbf{D}\) do
  7. for \(i = 1\) to \(K\) do
  8. \(a_i \leftarrow \mathbf{w}_i \cdot \mathbf{x}\)
  9. \(h_i \leftarrow \tanh(a_i)\)// compute activation of hidden unit \(i\)
  10. end for
  11. \(\hat{y} \leftarrow \mathbf{v} \cdot \mathbf{h}\)// compute output unit
  12. \(e \leftarrow y - \hat{y}\)// compute error
  13. \(\mathbf{g} \leftarrow \mathbf{g} - e\,\mathbf{h}\)// update gradient for output layer
  14. for \(i = 1\) to \(K\) do
  15. \(\mathbf{G}_i \leftarrow \mathbf{G}_i - e\, v_i \big(1 - \tanh^2(a_i)\big)\, \mathbf{x}\)// update gradient for input layer
  16. end for
  17. end for
  18. \(\mathbf{W} \leftarrow \mathbf{W} - \eta\, \mathbf{G}\)// update input layer weights
  19. \(\mathbf{v} \leftarrow \mathbf{v} - \eta\, \mathbf{g}\)// update output layer weights
  20. end for
  21. return \(\mathbf{W}, \mathbf{v}\)

Highlighted: the two gradients we just derived.

Biases: append a constant 1 to \(\mathbf{x}\) and to \(\mathbf{h}\), so each \(\mathbf{w}_i\) and \(\mathbf{v}\) gets one extra weight (the same trick as \(x_0 = 1\) in linear regression).

Lines 7–12: forward pass. Lines 13–16: backward pass. Lines 18–19: one batch update after all examples. Next we run lines 8–15 by hand on one customer.

The Learned Decision Boundary

Back to XOR: Why We Need Biases

  • Same network and algorithm, trained on XOR (±1 inputs)
  • Without biases, tanh is odd, so the whole network is: \(f(-\mathbf{x}) = -f(\mathbf{x})\). XOR needs \(f(1, 1) = f(-1, -1) = -1\). Gradient descent settles at \(f = 0\) everywhere.
  • With biases, 9 of 10 random starts solve XOR. The other one gets stuck: training is sensitive to initialisation.
The XOR Hidden Space demo shows the same thing: untick “Use biases”.

Issues with training

  • Sensitive to initialization
    • Objective is non-convex, many local optima
  • In practice: start with random values rather than zeros
  • Many other hyperparameters
    • Number of hidden units
    • Number of hidden layers
    • Gradient descent learning rate
    • Stopping criterion

Online vs Batch Update

  • Online (aka Stochastic Gradient Descent)
    • Update parameters after forward-propagation on every example
  • Batch and Mini-batch
    • Update parameters after forward-propagation on all examples (batch, as in Algorithm 25) or on a small random subset (mini-batch SGD)
  • Stochastic Gradient Descent Variants
    • Adam, AdaGrad
  • Why?
    • More robust
      • against noise (irrelevant features)
      • can be seen as a form of regularisation
    • More efficient (10M examples and Online? Nah…)
A sequence that works: 1) XOR corners with 2 hidden units, tanh: Play, then watch the boundary form. 2) Zeros initialisation: nothing moves (quick check 2). 3) Circles or Moons: try 2 hidden units, then 8. 4) Spiral: needs many more hidden units; compare the train and test results. 5) Raise the learning rate until the loss jumps, as at iteration 76 in our example. 6) Batch vs Online on the same data.

Summary

  • A perceptron draws one line, so it cannot learn XOR. A hidden layer of tanh units moves the data to a space where one line works.
  • A two-layer network \(\hat{y} = \mathbf{v} \cdot \tanh(\mathbf{W} \cdot \mathbf{x})\) (with biases) can approximate any continuous function, given enough hidden units; more units mean more complex functions and a risk of overfitting.
  • Backpropagation = gradient descent + chain rule
    • output weights: \(\nabla_{\mathbf{v}} = -e\,\mathbf{h}\), linear regression on the hidden features
    • hidden weights: \(\nabla_{\mathbf{w}_i} = -e\, v_i (1 - h_i^2)\, \mathbf{x}\), the error sent back through \(v_i\) and the tanh slope
  • In practice: the loss is non-convex, so start from small random weights, keep the biases, and tune \(\eta\), \(K\) and batch vs online.
