Neural Networks:

Multi-layer Perceptrons

Recap: Perceptron

  • Perceptron: single neuron
  • Receives input from D-many neurons
  • Each input has a weight
  • Cell sums up weighted input
  • Neuron “fires” if sum > 0

Say: a perceptron is one artificial neuron: a weighted sum of its inputs, and it “fires” if the sum is above 0. The inspiration is biological: dendrites bring signals in, the cell body adds them up, the axon sends the result on.

Neural Networks: Multi-layer Perceptrons

  • We can think of neural networks as combination of multiple perceptrons
    • Multilayer perceptron (MLP)
  • Why would we want to do that?
    • Discover more complex (a.k.a. non-linear) decision boundaries
    • Learn combinations of features

Say: stack perceptrons. A layer of hidden units, each one a perceptron-like line, feeds an output unit that combines them. Combining several lines lets the network draw bent boundaries, and the hidden units learn useful combinations of features by themselves.

Let’s design a 2-layer MLP

  • Layer-2: \(\hat{y} = g(\mathbf{v} \cdot \mathbf{h})\)
  • Layer-1: \(h_i = f(\mathbf{w}_i \cdot \mathbf{x})\)
  • \(f, g\) are called activation/link functions
    • hyperbolic tangent (\(\tanh\))
    • Sigmoid \(\sigma(x) = \frac{1}{e^{-x} + 1}\)
    • Rectified Linear Unit (ReLU)
    • Identity (usually not in Layer-1)
  • Set \(f = \tanh,\ g = \mathit{identity}\)
  • \(\hat{y} = \class{p-sum}{\sum_i} \class{p-v}{v_i} \class{p-tanh}{\tanh(\class{p-dot}{\mathbf{w}_i \cdot \mathbf{x}})} = \mathbf{v} \cdot \tanh(\mathbf{W} \cdot \mathbf{x})\)
  1. \(\mathbf{w}_i \cdot \mathbf{x}\)hidden unit \(i\)’s weighted sum of the inputs: a perceptron’s score
  2. \(\tanh(\ldots)\)squashed into \((-1, 1)\): this is the hidden unit’s output \(h_i\)
  3. \(v_i\)how much the output listens to hidden unit \(i\)
  4. \(\sum_i\)add over the hidden units: the output is a weighted sum of their outputs
  5. in wordsweighted sums, squashed by tanh, then a weighted sum of those

Clicks: the caption under the picture reads the last equation from the inside out: 1) weighted sum, 2) tanh, 3) the output weight v_i, 4) the sum over hidden units, 5) the whole thing in words.

Say: two layers. Layer 1: each hidden unit i takes a weighted sum of the inputs, w_i·x, and passes it through an activation f. Layer 2: the output takes a weighted sum of the hidden outputs with weights v and passes it through g. We choose f = tanh and g = identity (no squashing at the output).

Say: the last line writes all hidden units at once: tanh(W·x) is the list of hidden outputs, and v· that list is the output.

One Forward Pass, Labelled

  1. \(\mathbf{x}\)the inputs: one example, e.g. a customer’s three services
  2. \(\mathbf{w}_1\)the weights into hidden unit 1, one per input
  3. \(a_1\)unit 1’s weighted sum \(\mathbf{w}_1 \cdot \mathbf{x}\), like a perceptron’s score
  4. \(h_1\)\(\tanh(a_1)\): squashed into \((-1, 1)\), the unit’s output
  5. unit 2the same, with its own weights \(\mathbf{w}_2\)
  6. \(v_1, v_2\)how much the output listens to each hidden unit
  7. \(\hat{y}\)\(v_1 h_1 + v_2 h_2\): the output
  8. \(e, L\)the error \(y - \hat{y}\) and the loss \(\frac{1}{2}e^2\) for this example
  9. biasin practice a constant 1 joins \(\mathbf{x}\) and \(\mathbf{h}\), so each unit gets one extra weight

Why this slide: every later slide uses these names. Here they are on one picture, in the order the computation happens.

Clicks: 1) the inputs x. 2) the weights into hidden unit 1. 3) a₁, its weighted sum. 4) h₁ = tanh(a₁), its output. 5) unit 2 does the same with its own weights. 6) the output weights v₁, v₂. 7) the output ŷ = v₁h₁ + v₂h₂. 8) the error e = y − ŷ and the loss ½e². 9) the bias note.

Say: forward means left to right: inputs → weighted sums → tanh → weighted sum → output → error. Backpropagation will run right to left along the same picture.

Watch out: a_i is the weighted sum before tanh; h_i is after tanh. Keep the two apart: the gradient needs both.

Activation Functions

  • Activation functions are usually non-linear functions
  • Surrogates to non-linear as in the perceptron
  • BUT they are differentiable!
    • hyperbolic tangent \((-1, 1)\)
    • Sigmoid \((0, 1)\)

Say: the perceptron used the sign function (green in the plot): a hard step. It has no useful slope: flat everywhere except a jump at 0, so gradient descent gets no direction from it. tanh and the sigmoid are smooth versions of the step, so they have a slope everywhere.

Refresher: tanh goes from −1 to 1 and the sigmoid from 0 to 1, but they are the same shape: tanh(a) = 2σ(2a) − 1. The slope of tanh is 1 − tanh², largest (1) at 0 and close to 0 far from 0.

\(\tanh(5) \approx 0.9999\), so each hidden unit is almost a ±1 switch.

  1. OR\(5x_1 + 5x_2 + 5\) is negative only when both inputs are \(-1\) (it is \(-5\)), so \(h_1 \approx +1\) unless both are off

How the Hidden Layer Solves XOR

Say: left: each hidden unit draws one line, h₁ = 0 (teal) and h₂ = 0 (orange). The blue band between them is where the network says +.

Say: right: instead of plotting each input at (x₁, x₂), plot it at its hidden values (h₁, h₂). The two + inputs land on the same point, and now one straight line separates + from −. That is what a hidden layer does: it moves the data to a space where the problem becomes linear.

A sequence that works: 1) “Solved: OR and not AND” shows the weights from the last slide. 2) Drag a hidden-unit slider and watch its line move on the left and the points move on the right. 3) “Random start”, then Play: training finds its own solution. 4) Untick “Use biases”: (1,1) and (−1,−1) are forced to opposite sides, so one is always wrong. 5) Switch the hidden activation to identity: hidden space becomes a stretched copy of input space, and XOR stays unsolved.

Function Approximation with Neural Networks

  • Problem formulation
    • Set of possible instances \(X\)
      • Each instance \(\mathbf{x} \in X\) is a feature vector \(\mathbf{x} = [x_1, \ldots, x_D]\)
    • Unknown target function \(f: X \rightarrow Y\)
      • \(Y\) is binary valued \(\{-1, +1\}\)
    • Set of function hypotheses \(H = \{h \mid h: X \rightarrow Y\}\)
      • ???
  • Input
    • Training examples \(\{(\mathbf{x}^{(1)}, y^{(1)}), \ldots, (\mathbf{x}^{(N)}, y^{(N)})\}\) of unknown target function \(f\)
  • Output
    • Hypothesis \(h \in H\) that best approximates function \(f\)

Say: the general learning set-up: examples x with labels from some unknown function f; we choose a hypothesis h from a set H that matches f as well as possible on the training data.

Ask: what is H for a neural network? (Every function the network can compute with this architecture: one function for each setting of the weights W and v.) The next slide says how big that set is.

Two-Layer Networks are Universal Function Approximators

Theorem: Let \(F\) be a continuous function on a closed, bounded subset of \(D\)-dimensional space, and let \(\epsilon > 0\). Then there exists a two-layer neural network \(\hat{F}\) (sigmoid or tanh hidden units with biases, linear output) with a finite number of hidden units that approximates \(F\) arbitrarily well. Namely, for all \(\mathbf{x}\) in the domain of \(F\), \[ |F(\mathbf{x}) - \hat{F}(\mathbf{x})| < \epsilon \]

… or put simply, with enough hidden units, two-layer networks can approximate any continuous function on a bounded region!

Say in plain words: give a two-layer network enough hidden units and it can match any unbroken (continuous) curve, one you could draw without lifting the pen, even with corners, as closely as you like over a limited range. Picture each tanh unit as a smooth step; with enough steps of the right heights in the right places you can trace any curve, like building a hill from bricks.

Say: the theorem says such a network exists. It does not say how many hidden units we need, or that gradient descent will find the weights.

The conditions matter: the function must be continuous, the region closed and bounded, and the hidden units need biases (the XOR slides later show that a tanh network without biases cannot output any constant except 0: its output at −x is always minus its output at x).

Design Question

  • How many hidden units? How many layers?
    • Inductive bias / Regularisation
    • More hidden units yield more complex functions
      • Overfitting
    • Fewer hidden units requires fewer examples to train

Say: the number of hidden units K is a choice we make (a hyperparameter). More units: more flexible, but they can memorise noise (overfitting) and need more data. Fewer units: simpler functions that need fewer examples. In practice, try a few values and compare them on validation data.

Training Neural Networks:

Backpropagation

Training Neural Networks

Backpropagation algorithm =

Gradient descent + Chain rule

  • Forward: compute \(\mathbf{h}\) and \(\hat{y}\), layer by layer
  • Backward: pass the error back down, layer by layer (the arrows), to get every weight’s gradient

Say: training is gradient descent, as in Lecture 1. The new difficulty: the hidden weights affect the loss only indirectly, through the hidden units and then the output. The chain rule handles that. Computing the slopes layer by layer, from the output back towards the inputs (the blue arrows), is called backpropagation.

What’s our training objective?

  • We will consider the following objective \[ \min_{\mathbf{W}, \mathbf{v}} L(\mathbf{W}, \mathbf{v}) = \class{p-min}{\min_{\mathbf{W}, \mathbf{v}}} \class{p-sum}{\sum_n} \class{p-half}{\frac{1}{2}} \Big( \class{p-y}{y_n} - \class{p-yhat}{\sum_i v_i \cdot f(\mathbf{w}_i \cdot \mathbf{x}_n)} \Big)^2 \quad \text{where} \quad \hat{y}_n = \sum_i v_i \cdot f(\mathbf{w}_i \cdot \mathbf{x}_n) \]
    • i.e., our goal is to find parameters \(\mathbf{W}, \mathbf{v}\) that minimise squared error
    • \(N\) examples with \(\mathbf{x}_n, y_n\)
  • Other objectives are possible (exponential, logistic, etc.)
  • Weight regularisation
  1. \(\min_{\mathbf{W}, \mathbf{v}}\)find the hidden weights \(\mathbf{W}\) and output weights \(\mathbf{v}\) that make the rest as small as possible
  2. \(\sum_i v_i f(\ldots)\)the network’s prediction \(\hat{y}_n\): the hidden outputs, weighted by \(\mathbf{v}\)
  3. \(y_n - \hat{y}_n\)the error on example \(n\), squared as in Lecture 1
  4. \(\frac{1}{2}\)a convenience: it cancels the 2 that appears when we take the slope of the square
  5. \(\sum_n\)add over all \(N\) training examples
  6. sothe same squared error as Lecture 1, with the network as the predictor

Clicks: 1) min over W and v. 2) the network’s prediction. 3) the error. 4) the ½. 5) the sum over examples. 6) the whole objective again.

Say: the same squared error as Lecture 1. The only change is what ŷ is: before, a weighted sum of the inputs; now, a weighted sum of the hidden outputs, which are themselves tanh of weighted sums of the inputs.

For the ½: it changes nothing about where the minimum is. It is there so that, when we take the slope of the square, the 2 from the square cancels it and the formulas come out clean.

Recap: General Gradient Descent Algorithm

Algorithm: GRADIENT DESCENT(\(L(\mathbf{w}, b; \mathbf{D}), \mathbf{D}, maxIter, \eta_1, \ldots, \eta_k\))
  1. \(\mathbf{w}^{(0)} \leftarrow \langle 0, 0, \ldots, 0 \rangle,\ b^{(0)} \leftarrow 0\)// initialise the weights vector and bias
  2. for \(k = 1 \ldots maxIter\) do
  3. \(\mathbf{g}^{(k)} \leftarrow \nabla_{\mathbf{w}, b} L(\mathbf{w}, b; \mathbf{D})\big|_{\mathbf{w}^{(k-1)}, b^{(k-1)}}\)// gradient (slope of the loss) at the current point
  4. \(\mathbf{w}^{(k)} \leftarrow \mathbf{w}^{(k-1)} - \eta^{(k)} \mathbf{g}^{(k)}\)// step down the gradient
  5. \(b^{(k)} \leftarrow b^{(k-1)} - \eta^{(k)} \frac{\partial L}{\partial b}\)// update the bias the same way
  6. end for
  7. return \(\mathbf{w}^{(k)}, b^{(k)}\)
Greek letters
\(\eta\) (eta): learning rate, the step size
\(\nabla\) (nabla): gradient, the vector of partial derivatives
\(\partial\): partial derivative
Notation
\(\mathbf{w}^{(k)}\): value of \(\mathbf{w}\) at iteration \(k\)
\(\langle 0, \ldots, 0 \rangle\): vector of zeros
\(\leftarrow\): assignment
\(\big|_{\mathbf{w}^{(k-1)}, b^{(k-1)}}\): evaluated at the previous values
Variables
\(\mathbf{w}, b\): weights and bias we optimise
\(L\): loss, the prediction error
\(\mathbf{D}\): the training data
\(\mathbf{g}\): gradient, the update direction
\(k\): iteration number

Say: the general recipe from Lecture 1: start somewhere, compute the slope of the loss at the current weights, step against it, repeat. The legend below defines every symbol on the slide.

Say: the only new part for a network is line 3: we need the slope for every weight, in both layers. Backprop is how we compute it.

Backprop Toolbox: Five Facts

The next slides use only these. Keep them in view while we derive the gradients.

1 · Chain rule If \(L\) depends on \(w\) only through \(u\): \(\quad \dfrac{\partial L}{\partial w} = \dfrac{\partial L}{\partial u} \cdot \dfrac{\partial u}{\partial w}\) Used at every step: follow the path from the weight to the loss
2 · Squared error \(L = \frac{1}{2} e^2,\ e = y - \hat{y} \ \Rightarrow\ \dfrac{\partial L}{\partial \hat{y}} = -e\) The start of both gradients
3 · Weighted sum \(g = \sum_i v_i h_i \ \Rightarrow\ \dfrac{\partial g}{\partial v_i} = h_i,\ \ \dfrac{\partial g}{\partial h_i} = v_i\) Output weights, and passing the error back to \(h_i\)
4 · Dot product \(\dfrac{\partial (\mathbf{w}_i \cdot \mathbf{x})}{\partial \mathbf{w}_i} = \mathbf{x}\) Hidden weights (as in linear regression)
5 · tanh \(\tanh'(a) = 1 - \tanh^2(a)\) Going through the hidden activation

Say: five facts, all from Lecture 1 except tanh’s slope. Facts 2 and 3 cover the output layer; facts 4 and 5 are needed for the hidden layer; fact 1 glues them together.

Tip: copy these five onto the whiteboard (B) in a corner, then come back (B again) and point to each one when it is used. Most students who get lost in a derivation are missing one of these facts, not the logic.

Refresher on fact 5: tanh’s slope can be written with tanh itself: 1 − tanh²(a). At a = 0 it is 1 (steepest); at a = 3 it is 1 − 0.995² ≈ 0.01 (flat).

Backprop Is the Chain Rule Along a Path

How does the loss change if we nudge a weight in \(\mathbf{w}_1\)? Follow the path from that weight to the loss, and multiply the rate at each step (fact 1).

  1. \(-e\)how the loss reacts to the output (fact 2)
  2. \(v_1\)how the output reacts to \(h_1\) (fact 3)
  3. \(1 - h_1^2\)how \(h_1\) reacts to its weighted sum \(a_1\): the slope of tanh (fact 5)
  4. \(\mathbf{x}\)how \(a_1 = \mathbf{w}_1 \cdot \mathbf{x}\) reacts to \(\mathbf{w}_1\) (fact 4)
  5. T1with the numbers from our worked example: \(-1.0446 \times (-0.0469) \times 0.9613 \times \mathbf{x} \approx 0.0471\,\mathbf{x}\)
  6. every weightgets its gradient the same way: one path to the loss, one product
\[ \frac{\partial L}{\partial \mathbf{w}_1} = \class{c-e}{\underbrace{\frac{\partial L}{\partial \hat{y}}}_{-e}} \cdot \class{c-v}{\underbrace{\frac{\partial \hat{y}}{\partial h_1}}_{v_1}} \cdot \class{c-h}{\underbrace{\frac{\partial h_1}{\partial a_1}}_{1 - h_1^2}} \cdot \class{c-x}{\underbrace{\frac{\partial a_1}{\partial \mathbf{w}_1}}_{\mathbf{x}}} \]

Why this slide: the big picture before the formal derivation. The next eight slides only make each arrow on this path precise.

Say: how does the loss change if we nudge one weight going into hidden unit 1? The nudge travels a path: it changes a₁, which changes h₁, which changes ŷ, which changes the error and the loss. The chain rule says: multiply the rate at each step.

Clicks (backwards from the loss, which is why it is called backpropagation): 1) the loss reacts to the output with −e. 2) the output reacts to h₁ with v₁. 3) h₁ reacts to a₁ with tanh’s slope, 1 − h₁². 4) a₁ reacts to the weights with x. 5) the whole path, with the numbers for transaction T1 that we compute later. 6) every weight works the same way.

Say: notice what each factor means: the error, how much the output listens to this unit, how responsive the unit is, and the input. If any of them is 0, this weight does not change.

Two-layer NN: Gradient of output layer weights \(\mathbf{v}\) (1/3)

Where we’re heading\(\nabla_{\mathbf{v}} = -e_n \cdot \mathbf{h}_n\)line 13 of the backprop algorithm: \(\mathbf{g} \leftarrow \mathbf{g} - e\,\mathbf{h}\)

The loss function: \[ L(\mathbf{W}, \mathbf{v}) = \sum_n \frac{1}{2} \Big( y_n - \sum_i v_i \cdot f(\mathbf{w}_i \cdot \mathbf{x}_n) \Big)^2 \]

Breaking this down, for each training example \(n\):

  • the prediction: \(\hat{y}_n = \sum_i v_i \cdot f(\mathbf{w}_i \cdot \mathbf{x}_n)\)
  • the error: \(e_n = y_n - \hat{y}_n\)
  • the loss: \(L = \frac{1}{2} e_n^2\)

We want: how does the loss change when we change the output weight \(v_i\)? That is \(\dfrac{\partial L}{\partial v_i}\).

Say the destination first: by the end of three slides we will have line 13 of the algorithm, g ← g − e·h.

Say: the output layer is the easy one: v only touches the loss through ŷ. Break the loss down for one example: prediction, error, half the error squared. The question: how does the loss change when we change one output weight v_i?

Two-layer NN: Gradient of output layer weights \(\mathbf{v}\) (2/3)

We use \(g\) for the network output (the prediction). By the chain rule (fact 1): \[ \frac{\partial L}{\partial v_i} = \color{#3274B5}{\frac{\partial L}{\partial g}} \cdot \color{#A62B17}{\frac{\partial g}{\partial v_i}} \]

Part 1: how does the loss change with the prediction?

\(L = \frac{1}{2}(y_n - g)^2 = \frac{1}{2} e_n^2\)
\(\displaystyle \frac{\partial L}{\partial g} = \frac{\partial L}{\partial e} \cdot \frac{\partial e}{\partial g} = (y_n - g) \cdot (-1)\)
chain rule again: \(e = y_n - g\), so \(\partial e / \partial g = -1\)
\(\color{#3274B5}{\displaystyle \frac{\partial L}{\partial g} = -e_n}\)
fact 2

Part 2: how does the prediction change with \(v_i\)?

\(g = \mathit{identity}\Big(\sum_i v_i \cdot h_{i,n}\Big)\)
\(\phantom{g} = v_1 h_{1,n} + v_2 h_{2,n} + \ldots + v_K h_{K,n}\)
identity output: \(g\) is just the weighted sum
\(\color{#A62B17}{\displaystyle \frac{\partial g}{\partial v_i} = h_{i,n}}\)
fact 3: only the \(v_i h_{i,n}\) term contains \(v_i\). The prediction changes by exactly \(h_{i,n}\) when \(v_i\) changes by 1.

Notation: on these slides g means the network output (ŷ). In Algorithm 25, g is a different thing: the gradient for v. Say this out loud.

Clicks: Part 1 (blue): 1) the loss as ½e². 2–3) the chain rule through e: the slope of ½e² is e, and e = y − g goes down by 1 when g goes up by 1. 4–5) result −e. Part 2 (red): 6) g as a weighted sum. 7–8) written out term by term. 9–10) only one term contains v_i, so its slope is h_{i,n}.

Ask for Part 2: “which terms of the sum contain v_i?” (only v_i·h_i.)

Two-layer NN: Gradient of output layer weights \(\mathbf{v}\) (3/3)

Putting it together:

\[ \frac{\partial L}{\partial v_i} = \color{#3274B5}{-e_n} \cdot \color{#A62B17}{h_{i,n}} \]

In vector form, with \(\mathbf{h}_n = [h_{1,n}, h_{2,n}, \ldots]\) the hidden activations for example \(n\):

\[ \nabla_{\mathbf{v}} = \class{p-e}{-e_n} \cdot \class{p-h}{\mathbf{h}_n} \]
  1. \(-e_n\)the error: no error, no update
  2. \(\mathbf{h}_n\)the hidden outputs: a unit with a large output (near \(+1\) or \(-1\)) gets its outgoing weight changed most; a unit at 0 gets no change

The update rule*:

For a single example (online): \(\ \nabla_{\mathbf{v}} = -e_n \cdot \mathbf{h}_n\)

For all examples (batch): \(\ \nabla_{\mathbf{v}} = -\sum_n e_n \cdot \mathbf{h}_n\)

\[ \mathbf{v} \leftarrow \mathbf{v} - \eta \cdot \nabla_{\mathbf{v}} \]

* Assuming a linear (identity) activation at the output unit, \(g = \mathit{identity}(\sum_i v_i \cdot h_{i,n})\)

Compare with linear regression in Lecture 1: \(\mathbf{w} \leftarrow \mathbf{w} + \eta \cdot \delta \cdot \mathbf{x}_n\). The \(\mathbf{v}\) update is the same rule with the hidden features \(\mathbf{h}_n\) in place of the inputs \(\mathbf{x}_n\): for fixed hidden weights, the output layer is linear regression on \(\mathbf{h}_n\).

Two-layer NN: Gradient of hidden unit weights \(\mathbf{w}_i\) (1/4)

Where we’re heading\(\nabla_{\mathbf{w}_i} = -e\, v_i \big(1 - \tanh^2(a_i)\big)\, \mathbf{x}\)line 15 of the backprop algorithm, with \(a_i = \mathbf{w}_i \cdot \mathbf{x}\)

The loss function (one example): \[ L(\mathbf{W}, \mathbf{v}) = \frac{1}{2} \Big( y - \sum_i v_i \cdot f(\mathbf{w}_i \cdot \mathbf{x}) \Big)^2 = \frac{1}{2} e^2 \] where the error is \(e = y - \sum_i v_i \cdot f(\mathbf{w}_i \cdot \mathbf{x})\).

The chain rule: \[ \frac{\partial L}{\partial \mathbf{w}_i} = \color{#3274B5}{\frac{\partial L}{\partial f_i}} \cdot \color{#A62B17}{\frac{\partial f_i}{\partial \mathbf{w}_i}} \]

In simple words: \(\mathbf{w}_i\) only reaches the loss through the activation \(h_i = f_i = f(\mathbf{w}_i \cdot \mathbf{x})\) of hidden unit \(i\), so we go through it.

Say the destination: line 15 of the algorithm. It looks long, but it is the path from the earlier slide: error × v_i × tanh’s slope × x.

Two-layer NN: Gradient of hidden unit weights \(\mathbf{w}_i\) (2/4)

\[ \frac{\partial L}{\partial \mathbf{w}_i} = \color{#3274B5}{\frac{\partial L}{\partial f_i}} \cdot \frac{\partial f_i}{\partial \mathbf{w}_i} \]

Part 1: how does the loss change with the activation of hidden unit \(i\)?

Let \(g = \sum_i v_i \cdot f_i\), so \(L = \frac{1}{2}(y - g)^2\).

\(\displaystyle \frac{\partial L}{\partial f_i} = \frac{\partial L}{\partial g} \cdot \frac{\partial g}{\partial f_i}\)
chain rule: \(f_i\) reaches the loss through the output \(g\)
\(\displaystyle \frac{\partial L}{\partial g} = -e\)
from the output layer slides (fact 2)
\(g = v_1 f_1 + v_2 f_2 + \ldots + v_K f_K \ \Rightarrow\ \displaystyle \frac{\partial g}{\partial f_i} = v_i\)
fact 3, the other way round
\(\color{#3274B5}{\displaystyle \frac{\partial L}{\partial f_i} = -e \cdot v_i}\)
the output error, sent back to unit \(i\) and scaled by its outgoing weight

Clicks (each step is two clicks, the line then its reason): 1–2) the chain rule through the output g. 3–4) ∂L/∂g = −e, already known from the output layer. 5–6) g is a weighted sum of the f’s, so ∂g/∂f_i = v_i. 7–8) the result −e·v_i.

Say: this is the “back” in backpropagation: the error e at the output is passed back to each hidden unit, scaled by that unit’s outgoing weight v_i. A unit with a big v_i carries a big share of the blame.

Two-layer NN: Gradient of hidden unit weights \(\mathbf{w}_i\) (4/4)

Putting it together:

\[ \nabla_{\mathbf{w}_i} = \color{#3274B5}{-e\, v_i} \cdot \color{#A62B17}{f'(\mathbf{w}_i \cdot \mathbf{x})\, \mathbf{x}} \]

For tanh, the gradient \(f'\) is (fact 5): \(\quad f'(\mathbf{w}_i \cdot \mathbf{x}) = 1 - \tanh^2(\mathbf{w}_i \cdot \mathbf{x})\)

With \(a_i = \mathbf{w}_i \cdot \mathbf{x}\) (line 8 of the algorithm) and \(h_i = \tanh(a_i)\) (line 9):

\[ \nabla_{\mathbf{w}_i} = \class{p-e}{\underbrace{-e}_{\text{error}}} \cdot \class{p-v}{\underbrace{v_i}_{\text{how much the output uses } h_i}} \cdot \class{p-s}{\underbrace{\big(1 - \tanh^2(a_i)\big)}_{\text{slope of } h_i\text{, also } 1 - h_i^2}} \cdot \class{p-x}{\underbrace{\mathbf{x}}_{\text{input}}} \]
  1. \(-e\)the output’s error: no error, no update
  2. \(v_i\)how much the output listens to unit \(i\): if \(v_i \approx 0\), unit \(i\) gets almost no blame
  3. \(1 - h_i^2\)how responsive unit \(i\) is: near 1 when \(a_i\) is near 0, near 0 when tanh is saturated (\(h_i \approx \pm 1\))
  4. \(\mathbf{x}\)the inputs: a weight whose input is 0 does not change
  5. all fourerror × outgoing weight × slope × input: the same path as on the chain-rule slide

Clicks: 1) tanh’s slope (fact 5). 2) rewrite with a_i and h_i. Then the four factors one at a time: 3) the error, 4) v_i, 5) tanh’s slope, 6) x, 7) all four together.

Notation: a_i is the weighted input w_i·x (line 8 of the algorithm), and h_i = tanh(a_i) is the activation (line 9). So 1 − tanh²(a_i) = 1 − h_i², which is how the code computes it.

Two-layer NN: Gradient of hidden unit weights \(\mathbf{w}_i\)

  • Intuition
    • Small \(e\) \(\rightarrow\) small gradient
    • \(v_i\) small \(\rightarrow\) output not sensitive to activation of \(h_i\) \(\rightarrow\) small gradient
    • \(v_i\) flips sign \(\rightarrow\) gradient should also flip sign

Say: each bullet is one factor of the gradient. Small error → small gradient (the −e). v_i small → the output barely listens to unit i, so unit i barely gets blamed (the v_i). v_i negative instead of positive → the unit pushes the output the other way, so its correction goes the other way too (the sign of v_i).

Add the fourth factor: a saturated unit (h_i near ±1) has 1 − h_i² near 0 and learns slowly.

Backprop for 2-layer Network

Algorithm 25 TWO LAYER NETWORK TRAIN(\(\mathbf{D}, \eta, K, MaxIter\))
  1. \(\mathbf{W} \leftarrow D \times K\) matrix of small random values// initialise input layer weights
  2. \(\mathbf{v} \leftarrow K\)-vector of small random values// initialise output layer weights
  3. for \(iter = 1 \ldots MaxIter\) do
  4. \(\mathbf{G} \leftarrow D \times K\) matrix of zeros// initialise input layer gradient
  5. \(\mathbf{g} \leftarrow K\)-vector of zeros// initialise output layer gradient
  6. for all \((\mathbf{x}, y) \in \mathbf{D}\) do
  7. for \(i = 1\) to \(K\) do
  8. \(a_i \leftarrow \mathbf{w}_i \cdot \mathbf{x}\)
  9. \(h_i \leftarrow \tanh(a_i)\)// compute activation of hidden unit \(i\)
  10. end for
  11. \(\hat{y} \leftarrow \mathbf{v} \cdot \mathbf{h}\)// compute output unit
  12. \(e \leftarrow y - \hat{y}\)// compute error
  13. \(\mathbf{g} \leftarrow \mathbf{g} - e\,\mathbf{h}\)// update gradient for output layer
  14. for \(i = 1\) to \(K\) do
  15. \(\mathbf{G}_i \leftarrow \mathbf{G}_i - e\, v_i \big(1 - \tanh^2(a_i)\big)\, \mathbf{x}\)// update gradient for input layer
  16. end for
  17. end for
  18. \(\mathbf{W} \leftarrow \mathbf{W} - \eta\, \mathbf{G}\)// update input layer weights
  19. \(\mathbf{v} \leftarrow \mathbf{v} - \eta\, \mathbf{g}\)// update output layer weights
  20. end for
  21. return \(\mathbf{W}, \mathbf{v}\)

Highlighted: the two gradients we just derived.

Biases: append a constant 1 to \(\mathbf{x}\) and to \(\mathbf{h}\), so each \(\mathbf{w}_i\) and \(\mathbf{v}\) gets one extra weight (the same trick as \(x_0 = 1\) in linear regression).

Line by line: 1–2) small random starting weights (not zeros: quick check 2). 3) repeat MaxIter times. 4–5) reset the gradient totals: G for the hidden weights (one column per hidden unit) and g for the output weights. Here g is the gradient, not the output. 6) loop over the examples. 7–10) forward pass through the hidden layer: weighted sum a_i, then h_i = tanh(a_i). 11) the output ŷ = v·h. 12) the error. 13) add this example’s output-weight gradient, −e·h, to g. 14–16) add this example’s hidden-weight gradient for each unit. 17) end of the loop over examples. 18–19) one update with the totals: batch learning. 21) return the weights.

Say: lines 7–12 are the forward pass, lines 13–16 the backward pass. The highlighted lines are the two gradients we derived. Next we run lines 8–15 by hand on one customer.

Back to XOR: Why We Need Biases

  • Same network and algorithm, trained on XOR (±1 inputs)
  • Without biases, tanh is odd, so the whole network is: \(f(-\mathbf{x}) = -f(\mathbf{x})\). XOR needs \(f(1, 1) = f(-1, -1) = -1\), but the two must have opposite signs. Gradient descent settles at \(f = 0\) on all four points (loss 2).
  • With biases, 9 of 10 random starts solve XOR. The other one gets stuck: training is sensitive to initialisation.

Say: back to XOR, trained with the same algorithm. With biases it reaches zero loss by about iteration 70. Without biases the loss is stuck at 2.

Why, in plain words: tanh is “odd”: tanh(−a) = −tanh(a). Without biases, flipping the sign of every input flips every weighted sum, every hidden output and the final output: f(−x) = −f(x). (1, 1) and (−1, −1) are opposite inputs, so they get opposite outputs, but XOR needs both to be −1. The best compromise is 0 for every point, which gives loss ½ × 4 × 1² = 2.

Click: with biases, 9 of 10 random starts solve XOR; one gets stuck. Leads into the next slide.

Issues with training

  • Sensitive to initialization
    • Objective is non-convex, many local optima
  • In practice: start with random values rather than zeros
  • Many other hyperparameters
    • Number of hidden units
    • Number of hidden layers
    • Gradient descent learning rate
    • Stopping criterion

Say: the loss surface of a network is not one bowl but a landscape with many valleys (non-convex), so where you end up depends on where you start: that is the stuck XOR run. Starting from all zeros is worse: every hidden unit stays the same (quick check 2), so we start from small random values.

Say: many choices are ours, not learned: the number of hidden units and layers, the learning rate, when to stop. They are tuned by trying values and checking on validation data.

Online vs Batch Update

  • Online (aka Stochastic Gradient Descent)
    • Update parameters after forward-propagation on every example
  • Batch and Mini-batch
    • Update parameters after forward-propagation on all examples (batch, as in Algorithm 25) or on a small random subset (mini-batch SGD)
  • Stochastic Gradient Descent Variants
    • Adam, AdaGrad
  • Why?
    • More robust
      • against noise (irrelevant features)
      • can be seen as a form of regularisation
    • More efficient (10M examples and full batch? Nah…)

Say: batch: add up the gradient over all examples, then take one step. Smooth, but each step costs a full pass over the data. Online (stochastic gradient descent): one step per example. Cheap and noisy, and the noise can help escape poor spots. Mini-batch: a small random group per step, the usual compromise.

Say: Adam and AdaGrad adjust the step size for each weight automatically; they are the default choice in modern libraries.

Ask: 10 million examples: why not full batch? (One step would need all 10 million examples first.) And why not pure online? (10 million tiny, noisy steps per pass, which modern hardware handles badly.) Hence mini-batches.

A sequence that works: 1) XOR corners with 2 hidden units, tanh: Play, then watch the boundary form. 2) Zeros initialisation: the hidden layer never moves; only the output bias learns, so the loss drops a little and stops (quick check 2). 3) Circles or Moons: try 2 hidden units, then 8. 4) Spiral: needs many more hidden units; compare the train and test results. 5) Raise the learning rate until the loss jumps, as at iteration 76 in our example. 6) Batch vs Online on the same data.

Summary

  • A perceptron draws one line, so it cannot learn XOR. A hidden layer of tanh units moves the data to a space where one line works.
  • A two-layer network \(\hat{y} = \sum_i v_i \tanh(\mathbf{w}_i \cdot \mathbf{x})\) (with biases) can approximate any continuous function on a closed, bounded region, given enough hidden units; more units mean more complex functions and a risk of overfitting.
  • Backpropagation = gradient descent + chain rule
    • output weights: \(\nabla_{\mathbf{v}} = -e\,\mathbf{h}\), the Lecture 1 update with \(\mathbf{h}\) in place of \(\mathbf{x}\)
    • hidden weights: \(\nabla_{\mathbf{w}_i} = -e\, v_i (1 - h_i^2)\, \mathbf{x}\), the error sent back through \(v_i\) and the tanh slope
  • In practice: the loss is non-convex, so results depend on the starting point. Start from small random (not zero) weights so the hidden units differ, keep the biases, and tune \(\eta\), \(K\) and batch vs online.

Say: four take-aways. (1) One line cannot solve XOR; a hidden layer moves the data until one line can. (2) With enough hidden units, a two-layer network can approximate any continuous function on a bounded region. (3) Backprop is gradient descent plus the chain rule; each weight’s gradient is a product along its path to the loss: error × outgoing weight × tanh’s slope × input. (4) In practice: random starting weights, keep the biases, choose η and K carefully.
