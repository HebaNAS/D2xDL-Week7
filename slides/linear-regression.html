Linear Function

  • A linear function of features \(x_1, x_2, \ldots, x_D\) is a function that takes the form:
    \[ f_{\mathbf{w}}(x_1, x_2, \ldots, x_D) = \class{p-w0}{w_0} + \class{p-terms}{w_1x_1 + \ldots + w_Dx_D} = \class{p-sum}{\sum_{d=0}^{D} w_d x_d} = \class{p-dot}{\mathbf{w}^T \cdot \mathbf{x}} \]
    where \(x_0 = 1\)
  1. \(w_0\)the bias: the output when every feature is 0, a starting value
  2. \(w_d\, x_d\)each feature times its weight: a big weight means that feature moves the output a lot
  3. \(\sum\)shorthand for the same sum: add \(w_d x_d\) for \(d = 0, 1, \ldots, D\). With \(x_0 = 1\), the bias \(w_0\) is included
  4. \(\mathbf{w}^T \cdot \mathbf{x}\)the same thing again: line up the two lists, multiply matching entries, add up
  5. e.g.\(\mathbf{w} = [1, 2, 3, 1]\) and \(\mathbf{x} = [1, 0, 1, 1]\): \(\ 1 \cdot 1 + 2 \cdot 0 + 3 \cdot 1 + 1 \cdot 1 = 5\)

Clicks: 1) w₀ 2) each w_d·x_d 3) the Σ 4) wᵀ·x 5) a worked example.

Say: A linear model is a weighted sum. Each feature gets a weight; multiply and add. The bias w₀ is the starting value when every feature is 0.

For the Σ: “Σ from d = 0 to D” means “for d = 0, 1, …, D, add up what follows”. It is a compact way to write the long sum. The trick x₀ = 1 lets w₀ join the sum, because w₀·1 = w₀.

For wᵀ·x: the third way of writing the same number. Line up the weights and the features, multiply the pairs, add. In code this is a loop, or numpy’s dot.

Example: w = [1, 2, 3, 1] and x = [1, 0, 1, 1] (transaction T1 with the bias): 1 + 0 + 3 + 1 = 5. We meet this exact sum again in the hand calculation.

Ask: in w = [1, 2, 3, 1] (bias, Music DL, Music Stream, Online Games), which service has weight 3? Which one pushes the output up most when it is switched on? (Music Stream, weight 3.)

Linear Regression

  • “Linear regression is the problem of fitting a linear function to a set of \(n\) examples, in which usually the input and output features are numeric.”
  • Aim: predict the output feature \(\hat{Y}\) from input features \(x_1, x_2, \ldots, x_D\)
  • Notation:
    • A feature is a function of an example \(\rightarrow\) often a human interpretation
    • The weights denote the “importance” of features
    • The sum of squared errors (SSE) on examples \(X\) for output feature \(Y\) is: \[ SSE(\mathbf{X}, \mathbf{w}) = \class{p-sum}{\sum_{\mathbf{x}_n \in X}} \big(\class{p-y}{Y(\mathbf{x}_n)} - \class{p-yhat}{\hat{Y}(\mathbf{x}_n)}\big)^{\class{p-sq}{2}} \]
  1. \(Y(\mathbf{x}_n)\)the true output for example \(n\)
  2. \(\hat{Y}(\mathbf{x}_n)\)what the line predicts for it
  3. \((\ldots)^2\)square the gap: always positive, and big misses count much more (a miss of 2 costs 4, a miss of 10 costs 100)
  4. \(\sum\)add the squared gaps over every example: one number that says how bad the line is
  5. SSEtraining means finding the weights that make this number as small as possible

Clicks: the box under the plot walks through the SSE: true value, prediction, the square, the sum, then what training does with it.

Say: Each blue dot is one example; the red line is our model. For each dot, the vertical gap between dot and line is the error. The SSE squares every gap and adds them up: one number for how bad the line is. Training means finding the line with the smallest SSE.

Why square? (1) A gap below the line and a gap above it should not cancel out; squaring makes both positive. (2) Big misses count much more than small ones (2² = 4, 10² = 100). (3) It gives a smooth bowl shape that is easy to slide down, as we will see.

Watch out: Y(xₙ) means “the true output for example xₙ”, not Y times xₙ.

Linear Regression: the Optimisation Problem

  • Goal: find weights \(\mathbf{w}\) that minimise \(SSE(X, \mathbf{w})\)
  • Identical to optimising a linear model w.r.t. the squared objective function \(l^{(sqr)}\) over \(n\) examples without regularisation: \[ \class{p-min}{\min_{\mathbf{w}}} \class{p-sum}{\sum_n} \big(\class{p-y}{y_n} - \class{p-pred}{\mathbf{w}^T \cdot \mathbf{x}_n}\big)^2, \quad \text{where } w_0 = b \text{ (bias term) and } x_0 = 1 \]
  • For one example the gradient is \(\nabla_{\mathbf{w}} = \class{p-two}{-2}\,\class{p-err}{(y_n - \mathbf{w}^T \cdot \mathbf{x}_n)}\,\class{p-x}{\mathbf{x}_n}\), so gradient descent moves \(\mathbf{w}\) along \((y_n - \mathbf{w}^T \cdot \mathbf{x}_n)\,\mathbf{x}_n\)
    The 2 is absorbed into the learning rate \(\eta\).
  1. \(\min_{\mathbf{w}}\)find the weights (the bias is \(w_0\)) that make everything after it as small as possible
  2. \(\mathbf{w}^T \cdot \mathbf{x}_n\)the model’s prediction for example \(n\) (with \(x_0 = 1\), this already includes the bias)
  3. \(\sum (y_n - \ldots)^2\)true answer minus prediction, squared, added up: the SSE from the last slide
  4. \(y_n - \mathbf{w}^T \cdot \mathbf{x}_n\)the gradient (the slope of the loss for each weight) starts with the error on one example: the bigger the miss, the bigger the step
  5. \(\mathbf{x}_n\)times the example’s features: a feature that is 0 leaves its weight alone
  6. \(-2\)the 2 comes from the square; the minus because the error \(y_n - \mathbf{w}^T \cdot \mathbf{x}_n\) shrinks as \(\mathbf{w}\) grows
  7. updategradient descent subtracts the gradient; the two minuses cancel, so \(\mathbf{w} \leftarrow \mathbf{w} + \eta \cdot \delta \cdot \mathbf{x}_n\)

Clicks: min → prediction → the SSE → then the one-example gradient: error, features, the −2 → the update.

Say: “min over w” is an instruction: search all possible weights for the ones that make this sum smallest. The bias is one of them (w₀, with x₀ = 1). The thing inside is exactly the SSE from the last slide.

For the gradient: the gradient is the slope of the loss for each weight (it points uphill), and for one example it has three parts. The error: no error, no change. The features: only weights whose feature is switched on get nudged. The −2: the 2 comes from the square (the slope of u² is 2u); the minus comes from the error y − wᵀx, which goes down when w goes up (the same “−1” as on the chain-rule slide later). Gradient descent then subtracts the gradient, the two minuses cancel, and the update becomes w ← w + η·error·x.

Refresher: l^(sqr) is just a name for the squared error. Where this gradient comes from is shown properly after the worked example, on the derivative and chain-rule slides.

Linear Regression: Gradient Descent Algorithm

Algorithm: LINEAR REGRESSION GRADIENT DESCENT(data, \(maxIter\), \(\eta\))
  1. \(\mathbf{w} \leftarrow \langle 0, 0, \ldots, 0 \rangle\) or randomly initialise// initialise weights
  2. for \(k = 1 \ldots maxIter\) do
  3. for all \((\mathbf{x}_n, Y(\mathbf{x}_n)) \in\) data do
  4. \(\hat{Y}(\mathbf{x}_n) = \mathbf{w}^T \cdot \mathbf{x}_n\)// compute predicted output
  5. \(\delta = Y(\mathbf{x}_n) - \hat{Y}(\mathbf{x}_n)\)// compute scalar \(\delta\)
  6. \(\mathbf{w} \leftarrow \mathbf{w} + \eta \cdot \delta \cdot \mathbf{x}_n\)// update weights
  7. end for
  8. end for
  9. return \(\mathbf{w}\)

Lines 4–6 are one update. The next slide runs them live, one example at a time.

In words: guess, measure the error, nudge each weight by (step size) × (error) × (its feature), and repeat for every example, many times.

Say, line by line: 1) start with zeros or random weights. 2) repeat everything maxIter times; one pass over the data is an epoch. 3) visit every example. 4) predict: the weighted sum. 5) the error δ: true minus predicted. 6) the update: each weight moves by η × δ × its feature. 7–9) close the loops and return the weights.

Why line 6 makes sense: if the prediction was too low (δ > 0), the weights of the features that are switched on go up, so next time the prediction is higher. Too high (δ < 0): they go down. A feature that is 0 did not contribute to the mistake, so its weight is left alone. η keeps each step small so we don’t overshoot.

What a Derivative Tells Us

  • The derivative \(\frac{dL}{dw}\) is the slope of the loss: nudge \(w\) a little, and it says how much \(L\) changes, and in which direction
  • Example: one data point with input 1 and true answer 3, so \(L(w) = (3 - w)^2\) and \(\frac{dL}{dw} = -2(3 - w)\)
  • At \(w = 1\): slope \(-4\). Negative: the loss falls if \(w\) grows, so move right
  • At \(w = 5\): slope \(+4\). Positive: move left
  • Gradient descent: \(w \leftarrow w - \eta \cdot \text{slope}\). With \(\eta = 0.25\): \(w = 1 \to 2 \to 2.5 \to 2.75 \to \ldots \to 3\)
  • With many weights, \(\frac{\partial L}{\partial w_d}\) (“partial”) is the slope for one weight while the others stay put; \(\nabla L\) is the list of all of them

Purpose: a refresher for anyone whose calculus is rusty. Everything after this uses only this idea.

Say: A derivative answers one question: if I nudge this weight a tiny bit, does the loss go up or down, and how fast? That is the slope of the loss curve at that point.

Clicks: 1) The example: one data point with input 1 and true answer 3, so the loss is (3 − w)² and its slope is −2(3 − w). 2) At w = 1 the slope is −4 (the blue line slopes down): increasing w lowers the loss, so move right. 3) At w = 5 the slope is +4: move left. 4) Gradient descent always steps against the slope: w ← w − η × slope. With η = 0.25 from w = 1: 1 − 0.25 × (−4) = 2, then 2.5, then 2.75, closing in on 3, the bottom of the bowl. 5) With several weights we take one slope per weight (the “partial” derivative ∂, others held fixed) and collect them in a list, the gradient ∇.

Refresher: slope rules needed today: the slope of a constant is 0; of a·w it is a; of w² it is 2w. Near the bottom the slope itself shrinks, so the steps shrink too: that is why gradient descent slows down as it converges.

The Chain Rule in Plain Words

Effects pass along a chain, and the rates multiply. If 1 AED buys 0.27 USD and 1 USD buys 0.92 EUR, then 1 AED buys \(0.27 \times 0.92 \approx 0.25\) EUR.

If \(L\) depends on \(w\) only through some in-between quantity \(u\):

\[ \frac{dL}{dw} = \frac{dL}{du} \cdot \frac{du}{dw} \](how \(L\) reacts to \(u\)) × (how \(u\) reacts to \(w\))

Example from the last slide: \(L = u^2\) where \(u = 3 - w\) is the error.

\[ \frac{dL}{dw} = \class{p-out}{\frac{dL}{du}} \cdot \class{p-in}{\frac{du}{dw}} = \class{p-out}{2u} \cdot \class{p-in}{(-1)} = \class{p-res}{-2(3 - w)} \]
  1. \(\frac{dL}{du} = 2u\)outer step: \(L = u^2\), and the slope of a square is \(2u\)
  2. \(\frac{du}{dw} = -1\)inner step: \(u = 3 - w\) goes down by 1 when \(w\) goes up by 1
  3. \(-2(3 - w)\)multiply them: the same slope as on the last slide

Every derivation today follows the chain from a weight to the loss and multiplies the steps.

Say: Most losses are a function of a function: the loss depends on the error, and the error depends on the weight. The chain rule says: multiply the rates along the chain.

Analogy: currency. Dirhams → dollars → euros. If each dirham buys 0.27 dollars and each dollar buys 0.92 euros, each dirham buys 0.27 × 0.92 ≈ 0.25 euros. You never need a direct dirham-to-euro rate; you multiply the two you have. (Round made-up numbers, not today’s rates.)

Calculus Toolbox: Six Facts

The derivations in this lecture are built from these. Keep them in view.

1 · Chain rule If \(L\) depends on \(w\) only through \(u\): \(\ \dfrac{\partial L}{\partial w} = \dfrac{\partial L}{\partial u} \cdot \dfrac{\partial u}{\partial w}\) Used in every derivation today
2 · Power rule \(\dfrac{d}{du}\, u^2 = 2u\) The squared loss
3 · Linear term \(\dfrac{\partial (\mathbf{w}^T \mathbf{a})}{\partial \mathbf{w}} = \mathbf{a}\), so \(\dfrac{\partial (\mathbf{w}^T \cdot \mathbf{x})}{\partial \mathbf{w}} = \mathbf{x}\) Closed form, and every gradient that ends in \(\mathbf{x}_n\)
4 · Quadratic term \(\dfrac{\partial (\mathbf{w}^T A \mathbf{w})}{\partial \mathbf{w}} = 2A\mathbf{w}\) for symmetric \(A\) Closed form, with \(A = X^T X\)
5 · Sigmoid \(\sigma'(z) = \sigma(z)\big(1 - \sigma(z)\big)\) Logistic regression, with both losses
6 · Logarithm \(\dfrac{d}{du} \log u = \dfrac{1}{u}\) The log-loss

Say: Facts 1 and 2 are the last two slides. Facts 3 and 4 are the list-of-numbers versions of “the slope of a·w is a” and “the slope of a·w² is 2a·w”. Facts 5 and 6 are new; we use them in the logistic regression part.

Tip: copy these six onto the whiteboard (B) in a corner, then come back (B again) and point to each one when it is used. Most students who get lost in a derivation are missing one of these facts, not the logic.

Refresher on fact 5: the sigmoid’s slope can be written with the sigmoid itself: σ’(z) = σ(z)(1 − σ(z)). At z = 0, σ = 0.5, so the slope is 0.25, its largest value.

Linear Regression: Closed Form Solution

Where we’re heading\(\mathbf{w} = (X^T X)^{-1} X^T Y\)set the gradient of the SSE to zero and solve for \(\mathbf{w}\)
  • Our optimisation problem: minimise \(L(\mathbf{w}) = \sum_n \big(y_n - \mathbf{w}^T \cdot \mathbf{x}_n\big)^2\)
  • Matrix form: stack the examples as the rows of \(X\), so \(X\mathbf{w}\) holds every prediction \(\mathbf{w}^T \cdot \mathbf{x}_n = \mathbf{x}_n^T \cdot \mathbf{w}\), and \[ L(\mathbf{w}) = (Y - X\mathbf{w})^T (Y - X\mathbf{w}) \]
    • \(Y\): vector of all outputs \((N \times 1)\); \(X\): matrix of all inputs \((N \times D)\); \(\mathbf{w}\): weight vector \((D \times 1)\)
    • \((Y - X\mathbf{w})^T (Y - X\mathbf{w})\) is the dot product of the error vector with itself: the sum of squared errors
  • Expanding:
    \[ L(\mathbf{w}) = Y^T Y - Y^T X\mathbf{w} - (X\mathbf{w})^T Y + (X\mathbf{w})^T X\mathbf{w} \]
    \[ \phantom{L(\mathbf{w})} = Y^T Y - Y^T X\mathbf{w} - \mathbf{w}^T X^T Y + \mathbf{w}^T X^T X\mathbf{w} \]
    \[ \phantom{L(\mathbf{w})} = Y^T Y - 2\,\mathbf{w}^T X^T Y + \mathbf{w}^T X^T X\mathbf{w} \]
    because \(Y^T X\mathbf{w} = (Y^T X\mathbf{w})^T = \mathbf{w}^T X^T Y\): a single number equals its own transpose
    In words: the matrix version of \((a - b)^2 = a^2 - 2ab + b^2\)

Say the destination first: instead of walking downhill step by step, can we jump straight to the bottom? For linear regression, yes: w = (XᵀX)⁻¹XᵀY. Three slides get us there.

Say: the loss in matrix form is the last line of the previous slide. To find where its slope is zero, we first multiply out the brackets.

Clicks: 1) multiply out, like (a − b)(a − b) = a² − ab − ba + b². 2) rewrite (Xw)ᵀ as wᵀXᵀ, using (AB)ᵀ = BᵀAᵀ. 3) the two middle terms are the same single number, so they combine into −2wᵀXᵀY. 4) in words: this is (a − b)² = a² − 2ab + b².

Refresher: transposing a product reverses the order, (AB)ᵀ = BᵀAᵀ, and a single number is its own transpose. That is all the matrix algebra this needs.

Closed Form Solution: Taking the Gradient

Differentiate \(L(\mathbf{w}) = Y^T Y - 2\,\mathbf{w}^T X^T Y + \mathbf{w}^T X^T X\mathbf{w}\) term by term:

\(\dfrac{\partial}{\partial \mathbf{w}} \big(Y^T Y\big) = 0\)
\(Y^T Y\) does not contain \(\mathbf{w}\): a constant has slope 0
\(\dfrac{\partial}{\partial \mathbf{w}} \big(-2\,\mathbf{w}^T X^T Y\big) = -2\,X^T Y\)
fact 3, with \(\mathbf{a} = X^T Y\). One-number twin: \(\frac{d}{dw}(-2aw) = -2a\)
\(\dfrac{\partial}{\partial \mathbf{w}} \big(\mathbf{w}^T X^T X \mathbf{w}\big) = 2\,X^T X\mathbf{w}\)
fact 4, with \(A = X^T X\). One-number twin: \(\frac{d}{dw}(a w^2) = 2aw\)
Therefore \[ \nabla_{\mathbf{w}} L(\mathbf{w}) = 0 - 2\,X^T Y + 2\,X^T X\mathbf{w} = 2\,X^T X\mathbf{w} - 2\,X^T Y \]

Say: now take the slope of each of the three terms, one at a time.

Clicks (each term is two clicks, the slope then its reason): 1–2) YᵀY has no w in it: slope 0. 3–4) −2wᵀXᵀY is w times a fixed list, so the slope is the fixed list (fact 3); with single numbers, the slope of −2aw is −2a. 5–6) wᵀXᵀXw has w twice, like a·w², so the slope is 2XᵀXw (fact 4). 7) add them up.

Tip: keep the one-number twins on the board: d/dw (aw) = a and d/dw (aw²) = 2aw. Every line is just that, with matrices.

Refresher: fact 4 needs A to be symmetric (equal to its own transpose). XᵀX always is, because (XᵀX)ᵀ = XᵀX.

Closed Form Solution: Setting the Gradient to Zero

By setting the gradient \(\nabla_{\mathbf{w}} L(\mathbf{w}) = 0\):

\[ 2\,X^T X\mathbf{w} - 2\,X^T Y = 0 \]
\[ X^T X\mathbf{w} = X^T Y \qquad \text{(the normal equations)} \]
Multiply both sides by \((X^T X)^{-1}\): we cannot divide by a matrix.
\[ \mathbf{w} = \class{p-inv}{(X^T X)^{-1}} \class{p-xty}{X^T Y} \]

where \(X\) is the dataset \((N \times D)\) and \(Y\) are all the gold output values \((N \times 1)\). In code, solve the normal equations (np.linalg.solve(X.T @ X, X.T @ Y)) instead of forming the inverse.

  1. \(X^T Y\)for each feature, add up feature × true answer: how each feature lines up with the answers
  2. \((X^T X)^{-1}\)the matrix version of “divide by”: it undoes \(X^T X\), which adds up feature × feature
  3. 1 featurewith one feature and no bias, this is just \(w = \dfrac{\sum_n x_n y_n}{\sum_n x_n^2}\)

Say: at the bottom of a bowl the slope is zero in every direction. So set the gradient to zero and solve for w, as you would solve 2ax − 2b = 0 for x.

Clicks: 1) gradient = 0. 2) move the second term across: XᵀXw = XᵀY, the “normal equations”. 3) we cannot divide by a matrix, so we multiply both sides by its inverse instead. 4) the result. 5) what X and Y are. 6–7) its two parts in words. 8) the one-feature version.

Plain meaning of the normal equations: they can be written Xᵀ(Y − Xw) = 0. For every feature column, (feature × error) added over all examples is zero. With the bias column of 1s this says the errors add up to zero; for each feature, the errors show no leftover trend.

Closed Form Solution: Why Not Always Use It?

  • Complexity of gradient descent: \(\mathcal{O}(KND)\), where \(K\) is the number of iterations
  • Complexity of the closed form solution: \(\mathcal{O}(D^3 + D^2N)\)
    • Usually \(N > D\), so the cost is dominated by \(\mathcal{O}(D^2N)\)
  • Do we need to run more than \(D\)-many iterations \(K\)?
    • If we get good results with \(K < D\) (or even \(K \ll D\)), gradient descent can be very efficient, especially for high-dimensional problems where \(D^3\) is prohibitively expensive
    • In practice, far fewer than \(D\) iterations are often enough, which is one reason gradient descent is widely used in machine learning
  • Rule of thumb:
    • \(D \le 100 \rightarrow\) closed form is faster
    • \(D \ge 10{,}000 \rightarrow\) gradient descent is probably faster

Say: O(·), “big O”, is a rough count of how the work grows with the size of the problem; constant factors are ignored.

Say: gradient descent does K passes × N examples × D features. The closed form builds XᵀX (about D²N steps) and inverts a D × D table (about D³). Great when D is small; painful when D is huge: D³ for D = 10,000 is 10¹².

Logistic Regression

Recall: Binary Classification via Hyperplanes

  • A linear classifier is a hyperplane \((\mathbf{w}, b)\)
    • At test time, we check on which side of the hyperplane examples fall: \[ \hat{y} = \mathit{sign}(\mathbf{w}^T \cdot \mathbf{x} + b) \]
  • A linear regression
    • At test time, we use the value of the output directly: \[ \hat{Y}(\mathbf{x}) = \mathbf{w}^T \cdot \mathbf{x} \]
    • …and learn to “map” it to the pre-defined values of the gold classes, for example \(1 \rightarrow \mathit{true}\), \(0 \rightarrow \mathit{false}\)

Say: recall the perceptron: wᵀx + b is a score, the decision boundary is where the score is 0, and sign() turns the score into a class. Linear regression instead uses the score itself as the prediction and hopes it lands near 0 or 1.

Sigmoid (Logistic) Activation Function

  • What if we wanted to estimate the probability of the class \(P(\hat{Y}(\mathbf{x}) \mid \mathbf{x})\) directly from the input features \(\mathbf{x}_n\) with a linear model?
    • \(P(\hat{Y}(\mathbf{x}) \mid \mathbf{x}) = \mathbf{w}^T \cdot \mathbf{x}\) would not work: the output is not bounded to \([0, 1]\)
  • We can use the sigmoid (or logistic) function:
    • \(\sigma(z) = \class{p-frac}{\dfrac{1}{1 + \class{p-exp}{e^{-z}}}}\)
    • so that \[ P(\hat{Y}(\mathbf{x}) \mid \mathbf{x}) = \frac{1}{1 + e^{-\mathbf{w}^T \cdot \mathbf{x}}} \]
  1. \(e^{-z}\)always positive: huge when \(z\) is very negative, close to 0 when \(z\) is very positive
  2. \(\frac{1}{1 + \ldots}\)1 divided by something bigger than 1: always between 0 and 1
  3. values\(\sigma(-4) \approx 0.02,\ \ \sigma(0) = 0.5,\ \ \sigma(4) \approx 0.98\)

Clicks: e^(−z), then the fraction, then three values.

Say: we want a probability, so we need to squash the score z = wᵀx into (0, 1). The sigmoid does that.

For e^(−z): e ≈ 2.718. e to any power is positive. If z = 4, e^(−4) ≈ 0.018 (tiny); if z = −4, e^(4) ≈ 54.6 (huge).

For the fraction: 1/(1 + tiny) ≈ 1; 1/(1 + huge) ≈ 0; at z = 0, e⁰ = 1, so σ = 1/2. Big positive score → probability near 1; big negative → near 0; score 0 → 50/50.

  1. \(\mathbf{w} \leftarrow \langle 0, 0, \ldots, 0 \rangle\) or randomly initialise// initialise weights
  2. for \(k = 1 \ldots maxIter\) do
  3. for all \((\mathbf{x}_n, Y(\mathbf{x}_n)) \in\) data do
  4. \(\hat{Y}(\mathbf{x}_n) = \sigma(\mathbf{w}^T \cdot \mathbf{x}_n)\)// compute predicted output
  5. \(\delta = Y(\mathbf{x}_n) - \hat{Y}(\mathbf{x}_n)\)// compute scalar \(\delta\)
  6. \(\mathbf{w} \leftarrow \mathbf{w} + \eta \cdot \delta \cdot \hat{Y}(\mathbf{x}_n)\big(1 - \hat{Y}(\mathbf{x}_n)\big) \cdot \mathbf{x}_n\)// update weights

Say: the same algorithm as linear regression with two changes: line 4 passes the score through the sigmoid, and line 6 multiplies by the sigmoid’s slope Ŷ(1 − Ŷ). The −2 from the square is folded into η.

Ask: what happens on line 6 when Ŷ is 0.999 but the answer is 0? (almost no update: the model stays confidently wrong.) This is the motivation for the log-loss.

\(l^{(log)}\): Log Loss for Logistic Regression

  • Quite often, instead of the squared loss \(l^{(sqr)}\), we optimise the log-loss \(l^{(log)}\): \[ LL(\mathbf{w}) = \class{p-minus}{-}\sum_n \Big[ \class{p-one}{Y(\mathbf{x}_n) \cdot \log \hat{Y}(\mathbf{x}_n)} + \class{p-zero}{\big(1 - Y(\mathbf{x}_n)\big) \cdot \log\big(1 - \hat{Y}(\mathbf{x}_n)\big)} \Big] \] \[ \text{where } \hat{Y}(\mathbf{x}_n) = \sigma(\mathbf{w}^T \cdot \mathbf{x}_n) \]
  • Log-loss is the natural choice for logistic regression: it comes from probability theory (it is the negative log-likelihood of the labels) and has much better optimisation properties: better gradients and faster learning
  1. \(Y \log \hat{Y}\)switched on only when the true answer is \(Y = 1\): it looks at the probability we gave to “1”
  2. \((1 - Y) \log(1 - \hat{Y})\)switched on only when \(Y = 0\): it looks at the probability we gave to “0”
  3. \(-\)the log of a number below 1 is negative; the minus makes the loss positive
  4. soeach example costs \(-\log(\text{probability given to the right answer})\): next slide
Where we’re heading\(\dfrac{\partial LL_n}{\partial \mathbf{w}} = -\delta \cdot \mathbf{x}_n\)the same update as linear regression: the \(\hat{Y}(1 - \hat{Y})\) factor disappears

Clicks: the Y = 1 half, the Y = 0 half, the minus, the summary line.

Say: the log-loss looks long, but for each example only one half is switched on. If the true answer is 1, the second half is multiplied by 1 − Y = 0 and disappears, and the cost is −log Ŷ. If the answer is 0, the first half disappears, and the cost is −log(1 − Ŷ). Either way: −log(the probability we gave to the right answer).

Refresher: log here is the natural log (ln): ln p answers “e to what power gives p?”. ln 1 = 0; logs of numbers between 0 and 1 are negative, and they head towards −∞ as the number approaches 0. The minus sign turns them into positive costs.

“Negative log-likelihood”: the likelihood is the probability the model gives to all the observed labels together (a product over examples). Taking −log turns the product into a sum and “make the labels as probable as possible” into “make the loss as small as possible”.

Say the destination: the box at the bottom. The gradient of this loss is just −δ·x, the linear regression update, with no Ŷ(1 − Ŷ) factor.

Derivative of the Log Loss (1/3)

For a single example \(n\), writing \(Y\) and \(\hat{Y}\) for \(Y(\mathbf{x}_n)\) and \(\hat{Y}(\mathbf{x}_n)\): \[ LL_n = -Y \log \hat{Y} - (1 - Y) \log(1 - \hat{Y}) \]
By the chain rule: \[ \frac{\partial LL_n}{\partial \mathbf{w}} = \color{#3274B5}{\frac{\partial LL_n}{\partial \hat{Y}}} \cdot \color{#A62B17}{\frac{\partial \hat{Y}}{\partial \mathbf{w}}} \]

Part 1: \(\dfrac{\partial LL_n}{\partial \hat{Y}}\)

\(\displaystyle \frac{\partial}{\partial \hat{Y}} \Big[ -Y \log \hat{Y} - (1 - Y) \log(1 - \hat{Y}) \Big] = -\frac{Y}{\hat{Y}} - (1 - Y) \cdot \frac{1}{1 - \hat{Y}} \cdot (-1)\)
\(\log u\) has slope \(1/u\) (fact 6); inside \(\log(1 - \hat{Y})\), the \(1 - \hat{Y}\) has slope \(-1\) (chain rule)
\(\displaystyle = -\frac{Y}{\hat{Y}} + \frac{1 - Y}{1 - \hat{Y}} = \frac{-Y(1 - \hat{Y}) + (1 - Y)\hat{Y}}{\hat{Y}(1 - \hat{Y})}\)
put both fractions over the same bottom, \(\hat{Y}(1 - \hat{Y})\), so they can be added
\(\displaystyle = \frac{-Y + Y\hat{Y} + \hat{Y} - Y\hat{Y}}{\hat{Y}(1 - \hat{Y})} = \color{#3274B5}{\frac{\hat{Y} - Y}{\hat{Y}(1 - \hat{Y})}}\)
multiply out the top: \(+Y\hat{Y}\) and \(-Y\hat{Y}\) cancel

Say: the same chain-rule plan as before. Part 1: how the loss reacts to the prediction. Part 2: how the prediction reacts to the weights (we know this from the sigmoid). Then multiply.

Clicks (each step is two clicks, the line then its reason): 1–2) the slope of each log term: log u has slope 1/u; the second log has the inside 1 − Ŷ, whose slope is −1. 3–4) put both fractions over a common bottom so we can add them. 5–6) multiply out the top; the Y·Ŷ terms cancel. Result: (Ŷ − Y) / (Ŷ(1 − Ŷ)).

Derivative of the Log Loss (2/3)

Part 2: \(\dfrac{\partial \hat{Y}}{\partial \mathbf{w}}\), where \(\hat{Y} = \sigma(\mathbf{w}^T \cdot \mathbf{x})\)

We need the derivative of the sigmoid:

\[ \frac{\partial \sigma(z)}{\partial z} = \sigma(z)\big(1 - \sigma(z)\big) \]

So, by the chain rule:

\[ \frac{\partial \hat{Y}}{\partial \mathbf{w}} = \frac{\partial \sigma(\mathbf{w}^T \cdot \mathbf{x})}{\partial \mathbf{w}} = \sigma(\mathbf{w}^T \cdot \mathbf{x})\big(1 - \sigma(\mathbf{w}^T \cdot \mathbf{x})\big) \cdot \frac{\partial (\mathbf{w}^T \cdot \mathbf{x})}{\partial \mathbf{w}} \]
\[ = \color{#A62B17}{\hat{Y}(1 - \hat{Y}) \cdot \mathbf{x}} \]

Say: Part 2 is the same as in the squared-loss derivation: the sigmoid’s slope Ŷ(1 − Ŷ) (fact 5), times x from the inside wᵀx (fact 3).

Derivative of the Log Loss (3/3)

Part 3: combine them

\[ \frac{\partial LL_n}{\partial \mathbf{w}} = \color{#3274B5}{\frac{\partial LL_n}{\partial \hat{Y}}} \cdot \color{#A62B17}{\frac{\partial \hat{Y}}{\partial \mathbf{w}}} \]
\[ = \frac{\hat{Y} - Y}{\class{p-c}{\hat{Y}(1 - \hat{Y})}} \cdot \class{p-c}{\hat{Y}(1 - \hat{Y})} \cdot \mathbf{x} \]
\[ = (\hat{Y} - Y) \cdot \mathbf{x} = -(Y - \hat{Y}) \cdot \mathbf{x} = -\delta \cdot \mathbf{x}, \quad \text{where } \delta = Y - \hat{Y} \]
  1. \(\hat{Y}(1 - \hat{Y})\)the same factor on the bottom (from the log) and on top (the sigmoid’s slope): they cancel
The sigmoid derivative \(\hat{Y}(1 - \hat{Y})\) cancels the denominator from the log derivative. This is why the log-loss works so well with the sigmoid.

Clicks: 1) multiply the two parts. 2) the highlighted factor is on the bottom and on top: cancel it. 3) what is left: (Ŷ − Y)·x = −δ·x. 4) the take-away.

Say: the sigmoid’s slope, the factor that made the squared loss stall, is exactly cancelled by the 1/(Ŷ(1 − Ŷ)) from the log. That is no accident: the log-loss and the sigmoid are made to fit together.

Ask: before click 2, ask the room what cancels.

\(l^{(log)}\): Back to the Familiar Update

  • The gradient with respect to \(\mathbf{w}\) is \[ \nabla_{\mathbf{w}} LL(\mathbf{w}) = -\sum_n \delta \cdot \mathbf{x}_n, \quad \text{where } \delta = Y(\mathbf{x}_n) - \hat{Y}(\mathbf{x}_n) \] which brings us back to the familiar weight update: \[ \mathbf{w} \leftarrow \mathbf{w} + \eta \cdot \delta \cdot \mathbf{x}_n \]

Summary

  • Linear regression fits \(\hat{Y} = \mathbf{w}^T \cdot \mathbf{x}\) by minimising the SSE
    • gradient descent: \(\mathbf{w} \leftarrow \mathbf{w} + \eta \cdot \delta \cdot \mathbf{x}_n\); too small an \(\eta\) is slow, too large oscillates or diverges
    • closed form: \(\mathbf{w} = (X^T X)^{-1} X^T Y\), exact but \(\mathcal{O}(D^3 + D^2N)\); gradient descent \(\mathcal{O}(KND)\) wins for large \(D\)
  • Regression outputs are not probabilities. For classes, use logistic regression: \(\hat{Y} = \sigma(\mathbf{w}^T \cdot \mathbf{x})\)
    • with the sigmoid, the log-loss gives the simple gradient \(-\delta \cdot \mathbf{x}\); the squared loss adds \(\hat{Y}(1 - \hat{Y})\), which vanishes when the model is confidently wrong
    • without regularisation, the weights on (almost) separable data keep growing

Say: three ideas to take away. (1) Training means choosing weights that minimise a loss: walk downhill (gradient descent) or, for linear regression, solve directly (closed form). (2) Every update has the shape step × error × input. (3) For classification, put the score through a sigmoid and use the log-loss, so that confident mistakes get big corrections.
