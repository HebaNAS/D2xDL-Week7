Linear Function

  • A linear function of features \(x_1, x_2, \ldots, x_D\) is a function that takes the form: \[ f_{\mathbf{w}}(x_1, x_2, \ldots, x_D) = w_0 + w_1x_1 + \ldots + w_Dx_D = \sum_{d=0}^{D} w_d x_d = \mathbf{w}^T \cdot \mathbf{x} \] where \(x_0 = 1\)

Linear Regression

  • “Linear regression is the problem of fitting a linear function to a set of \(n\) examples, in which usually the input and output features are numeric.”
  • Aim: predict the output feature \(\hat{Y}\) from input features \(x_1, x_2, \ldots, x_D\)
  • Notation:
    • A feature is a function of an example \(\rightarrow\) often a human interpretation
    • The weights denote the “importance” of features
    • The sum of squared errors (SSE) on examples \(X\) for output feature \(Y\) is: \[ SSE(\mathbf{X}, \mathbf{w}) = \sum_{\mathbf{x}_n \in X} \big(Y(\mathbf{x}_n) - \hat{Y}(\mathbf{x}_n)\big)^2 \]

Linear Regression: the Optimisation Problem

  • Goal: find weights \(\mathbf{w}\) that minimise \(SSE(X, \mathbf{w})\)
  • Identical to optimising a linear model w.r.t. the squared objective function \(l^{(sqr)}\) over \(n\) examples without regularisation: \[ \min_{\mathbf{w}, b} \sum_n \big(y_n - (\mathbf{w}^T \cdot \mathbf{x}_n + b)\big)^2, \quad \text{where } w_0 = b \text{ (bias term) and } x_0 = 1 \]
  • For one example the gradient is \(\nabla_{\mathbf{w}} = -2\,(y_n - \mathbf{w}^T \cdot \mathbf{x}_n)\,\mathbf{x}_n\), so gradient descent moves \(\mathbf{w}\) along \((y_n - \mathbf{w}^T \cdot \mathbf{x}_n)\,\mathbf{x}_n\)
    The 2 is absorbed into the learning rate \(\eta\).

Gradient Descent in Action

Linear Regression: Gradient Descent Algorithm

Algorithm: LINEAR REGRESSION GRADIENT DESCENT(data, \(maxIter\), \(\eta\))
  1. \(\mathbf{w} \leftarrow \langle 0, 0, \ldots, 0 \rangle\) or randomly initialise// initialise weights
  2. for \(k = 1 \ldots maxIter\) do
  3. for all \((\mathbf{x}_n, Y(\mathbf{x}_n)) \in\) data do
  4. \(\hat{Y}(\mathbf{x}_n) = \mathbf{w}^T \cdot \mathbf{x}_n\)// compute predicted output
  5. \(\delta = Y(\mathbf{x}_n) - \hat{Y}(\mathbf{x}_n)\)// compute scalar \(\delta\)
  6. \(\mathbf{w} \leftarrow \mathbf{w} + \eta \cdot \delta \cdot \mathbf{x}_n\)// update weights
  7. end for
  8. end for
  9. return \(\mathbf{w}\)

Linear Regression: Closed Form Solution

  • Our optimisation problem: minimise \(L(\mathbf{w}) = \sum_n \big(y_n - \mathbf{w}^T \cdot \mathbf{x}_n\big)^2\)
  • Matrix form: stack the examples as the rows of \(X\), so \(X\mathbf{w}\) holds every prediction \(\mathbf{w}^T \cdot \mathbf{x}_n = \mathbf{x}_n^T \cdot \mathbf{w}\), and \[ L(\mathbf{w}) = (Y - X\mathbf{w})^T (Y - X\mathbf{w}) \]
    • \(Y\): vector of all outputs \((N \times 1)\); \(X\): matrix of all inputs \((N \times D)\); \(\mathbf{w}\): weight vector \((D \times 1)\)
    • \((Y - X\mathbf{w})^T (Y - X\mathbf{w})\) is the dot product of the error vector with itself: the sum of squared errors
  • Expanding:
    \[ L(\mathbf{w}) = Y^T Y - Y^T X\mathbf{w} - (X\mathbf{w})^T Y + (X\mathbf{w})^T X\mathbf{w} \]
    \[ \phantom{L(\mathbf{w})} = Y^T Y - Y^T X\mathbf{w} - \mathbf{w}^T X^T Y + \mathbf{w}^T X^T X\mathbf{w} \]
    \[ \phantom{L(\mathbf{w})} = Y^T Y - 2\,\mathbf{w}^T X^T Y + \mathbf{w}^T X^T X\mathbf{w} \]
    because \(Y^T X\mathbf{w} = (Y^T X\mathbf{w})^T = \mathbf{w}^T X^T Y\): a single number equals its own transpose

Closed Form Solution: Taking the Gradient

Differentiate \(L(\mathbf{w}) = Y^T Y - 2\,\mathbf{w}^T X^T Y + \mathbf{w}^T X^T X\mathbf{w}\) term by term:

\(\dfrac{\partial}{\partial \mathbf{w}} \big(Y^T Y\big) = 0\)
\(Y^T Y\) is a constant
\(\dfrac{\partial}{\partial \mathbf{w}} \big(-2\,\mathbf{w}^T X^T Y\big) = -2\,X^T Y\)
as \(\frac{\partial}{\partial \mathbf{w}}(\mathbf{w}^T \mathbf{a}) = \mathbf{a}\), with the constant \(\mathbf{a} = X^T Y\)
\(\dfrac{\partial}{\partial \mathbf{w}} \big(\mathbf{w}^T X^T X \mathbf{w}\big) = 2\,X^T X\mathbf{w}\)
as \(\frac{\partial}{\partial \mathbf{w}}(\mathbf{w}^T A \mathbf{w}) = 2A\mathbf{w}\) for symmetric \(A\); here \(A = X^T X\)
Therefore \[ \nabla_{\mathbf{w}} L(\mathbf{w}) = 0 - 2\,X^T Y + 2\,X^T X\mathbf{w} = 2\,X^T X\mathbf{w} - 2\,X^T Y \]

Closed Form Solution: Setting the Gradient to Zero

By setting the gradient \(\nabla_{\mathbf{w}} L(\mathbf{w}) = 0\):

\[ 2\,X^T X\mathbf{w} - 2\,X^T Y = 0 \]
\[ X^T X\mathbf{w} = X^T Y \qquad \text{(the normal equations)} \]
Multiply both sides by \((X^T X)^{-1}\): we cannot divide by a matrix.
\[ \color{#3274B5}{\mathbf{w} = (X^T X)^{-1} X^T Y} \]

where \(X\) is the dataset \((N \times D)\) and \(Y\) are all the gold output values \((N \times 1)\). In code, solve the normal equations (np.linalg.solve(X.T @ X, X.T @ Y)) instead of forming the inverse.

Closed Form Solution: Why Not Always Use It?

  • Complexity of gradient descent: \(\mathcal{O}(KND)\), where \(K\) is the number of iterations
  • Complexity of the closed form solution: \(\mathcal{O}(D^3 + D^2N)\)
    • Usually \(N > D\), so the cost is dominated by \(\mathcal{O}(D^2N)\)
  • Do we need to run more than \(D\)-many iterations \(K\)?
    • If we get good results with \(K < D\) (or even \(K \ll D\)), gradient descent can be very efficient, especially for high-dimensional problems where \(D^3\) is prohibitively expensive
    • In practice, far fewer than \(D\) iterations are often enough, which is one reason gradient descent is widely used in machine learning
  • Rule of thumb:
    • \(D \le 100 \rightarrow\) closed form is faster
    • \(D \ge 10{,}000 \rightarrow\) gradient descent is probably faster

Which Is Cheaper as \(D\) and \(N\) Grow?

Logistic Regression

Recall: Binary Classification via Hyperplanes

  • A linear classifier is a hyperplane \((\mathbf{w}, b)\)
    • At test time, we check on which side of the hyperplane examples fall: \[ \hat{y} = \mathit{sign}(\mathbf{w}^T \cdot \mathbf{x} + b) \]
  • A linear regression
    • At test time, we use the value of the output directly: \[ \hat{Y}(\mathbf{x}) = \mathbf{w}^T \cdot \mathbf{x} \]
    • …and learn to “map” it to the pre-defined values of the gold classes, for example \(1 \rightarrow \mathit{true}\), \(0 \rightarrow \mathit{false}\)

Sigmoid (Logistic) Activation Function

  • What if we wanted to estimate the probability of the class \(P(\hat{Y}(\mathbf{x}) \mid \mathbf{x})\) directly from the input features \(\mathbf{x}_n\) with a linear model?
    • \(P(\hat{Y}(\mathbf{x}) \mid \mathbf{x}) = \mathbf{w}^T \cdot \mathbf{x}\) would not work: the output is not bounded to \([0, 1]\)
  • We can use the sigmoid (or logistic) function:
    • \(\sigma(z) = \dfrac{1}{1 + e^{-z}}\)
    • so that \[ P(\hat{Y}(\mathbf{x}) \mid \mathbf{x}) = \frac{1}{1 + e^{-\mathbf{w}^T \cdot \mathbf{x}}} \]
Drag w: larger |w| gives a steeper curve and more confident predictions; a negative w flips it. Drag b: the 0.5 crossing moves to x* = −b/w.
Both models start with no errors. Press "Add a very large tumour" once or twice: the least-squares line tilts, its 0.5 crossing moves right and it misclassifies malignant cases; the S-curve barely moves. Point at the shaded areas: linear outputs below 0 or above 1 are not probabilities.

Use Case: Gradient Calculation for \(l^{(sqr)}\)

  • Consider the following learning objective: \[ L(\mathbf{w}) = \sum_n \big( Y(\mathbf{x}_n) - \hat{Y}(\mathbf{x}_n) \big)^2, \quad \text{where } \hat{Y}(\mathbf{x}_n) = \sigma(\mathbf{w}^T \cdot \mathbf{x}_n) \]
  • What do we need in order to run gradient descent?
    • The gradient \(\nabla_{\mathbf{w}} L\): how the loss changes as each weight changes

\(l^{(sqr)}\): Derivative with Respect to \(\mathbf{w}\) (1/2)

\(\nabla_{\mathbf{w}} L = \nabla_{\mathbf{w}} \sum_n \big( Y(\mathbf{x}_n) - \hat{Y}(\mathbf{x}_n) \big)^2 = \nabla_{\mathbf{w}} \sum_n \big( Y(\mathbf{x}_n) - \sigma(\mathbf{w}^T \cdot \mathbf{x}_n) \big)^2\)
\(= \sum_n 2 \big( Y(\mathbf{x}_n) - \sigma(\mathbf{w}^T \cdot \mathbf{x}_n) \big) \, \nabla_{\mathbf{w}} \big( Y(\mathbf{x}_n) - \sigma(\mathbf{w}^T \cdot \mathbf{x}_n) \big)\)
power rule (brings down the 2) + chain rule (multiply by the derivative of the inside)
\(= \sum_n 2 \big( Y(\mathbf{x}_n) - \sigma(\mathbf{w}^T \cdot \mathbf{x}_n) \big) \cdot \big( -\nabla_{\mathbf{w}} \, \sigma(\mathbf{w}^T \cdot \mathbf{x}_n) \big)\)
sum rule: the derivative of a difference is the difference of the derivatives; \(Y(\mathbf{x}_n)\) does not depend on \(\mathbf{w}\)

\(l^{(sqr)}\): Derivative with Respect to \(\mathbf{w}\) (2/2)

\(= \sum_n -2 \big( Y(\mathbf{x}_n) - \sigma(\mathbf{w}^T \cdot \mathbf{x}_n) \big) \, \sigma(\mathbf{w}^T \cdot \mathbf{x}_n) \big( 1 - \sigma(\mathbf{w}^T \cdot \mathbf{x}_n) \big) \, \nabla_{\mathbf{w}} \, \mathbf{w}^T \cdot \mathbf{x}_n\)
chain rule: the derivative of the sigmoid is \(\sigma(z)(1 - \sigma(z))\)
\(= \sum_n -2 \big( Y(\mathbf{x}_n) - \sigma(\mathbf{w}^T \cdot \mathbf{x}_n) \big) \, \sigma(\mathbf{w}^T \cdot \mathbf{x}_n) \big( 1 - \sigma(\mathbf{w}^T \cdot \mathbf{x}_n) \big) \, \mathbf{x}_n\)
the derivative of the dot product \(\mathbf{w}^T \cdot \mathbf{x}_n\) with respect to \(\mathbf{w}\) is \(\mathbf{x}_n\)
\(= \sum_n -2 \big( Y(\mathbf{x}_n) - \hat{Y}(\mathbf{x}_n) \big) \, \hat{Y}(\mathbf{x}_n) \big( 1 - \hat{Y}(\mathbf{x}_n) \big) \, \mathbf{x}_n\)
since \(\hat{Y}(\mathbf{x}_n) = \sigma(\mathbf{w}^T \cdot \mathbf{x}_n)\)
\(= \sum_n -2 \, \delta \, \hat{Y}(\mathbf{x}_n) \big( 1 - \hat{Y}(\mathbf{x}_n) \big) \, \mathbf{x}_n\)
let the error \(\delta = Y(\mathbf{x}_n) - \hat{Y}(\mathbf{x}_n)\)

Logistic Regression: Gradient Descent Algorithm

Algorithm: LOGISTIC REGRESSION GRADIENT DESCENT(data, \(maxIter\), \(\eta\)) (squared loss)
  1. \(\mathbf{w} \leftarrow \langle 0, 0, \ldots, 0 \rangle\) or randomly initialise// initialise weights
  2. for \(k = 1 \ldots maxIter\) do
  3. for all \((\mathbf{x}_n, Y(\mathbf{x}_n)) \in\) data do
  4. \(\hat{Y}(\mathbf{x}_n) = \sigma(\mathbf{w}^T \cdot \mathbf{x}_n)\)// compute predicted output
  5. \(\delta = Y(\mathbf{x}_n) - \hat{Y}(\mathbf{x}_n)\)// compute scalar \(\delta\)
  6. \(\mathbf{w} \leftarrow \mathbf{w} + \eta \cdot \delta \cdot \hat{Y}(\mathbf{x}_n)\big(1 - \hat{Y}(\mathbf{x}_n)\big) \cdot \mathbf{x}_n\)// update weights
  7. end for
  8. end for
  9. return \(\mathbf{w}\)

Compared with linear regression, only lines 4 and 6 change: the sigmoid, and its derivative \(\hat{Y}(1 - \hat{Y})\) in the update (the 2 is absorbed into \(\eta\)).

\(l^{(log)}\): Log Loss for Logistic Regression

  • Quite often, instead of the squared loss \(l^{(sqr)}\), we optimise the log-loss \(l^{(log)}\): \[ LL(\mathbf{w}) = -\sum_n \Big[ Y(\mathbf{x}_n) \cdot \log \hat{Y}(\mathbf{x}_n) + \big(1 - Y(\mathbf{x}_n)\big) \cdot \log\big(1 - \hat{Y}(\mathbf{x}_n)\big) \Big] \] \[ \text{where } \hat{Y}(\mathbf{x}_n) = \sigma(\mathbf{w}^T \cdot \mathbf{x}_n) \]
  • Log-loss is the natural choice for logistic regression: it comes from probability theory (it is the negative log-likelihood of the labels) and has much better optimisation properties: better gradients and faster learning

Derivative of the Log Loss (1/3)

For a single example \(n\), writing \(Y\) and \(\hat{Y}\) for \(Y(\mathbf{x}_n)\) and \(\hat{Y}(\mathbf{x}_n)\): \[ LL_n = -Y \log \hat{Y} - (1 - Y) \log(1 - \hat{Y}) \]
By the chain rule: \[ \frac{\partial LL_n}{\partial \mathbf{w}} = \color{#3274B5}{\frac{\partial LL_n}{\partial \hat{Y}}} \cdot \color{#A62B17}{\frac{\partial \hat{Y}}{\partial \mathbf{w}}} \]

Part 1: \(\dfrac{\partial LL_n}{\partial \hat{Y}}\)

\(\displaystyle \frac{\partial}{\partial \hat{Y}} \Big[ -Y \log \hat{Y} - (1 - Y) \log(1 - \hat{Y}) \Big] = -\frac{Y}{\hat{Y}} - (1 - Y) \cdot \frac{1}{1 - \hat{Y}} \cdot (-1)\)
derivative of \(\log\); the inner \(1 - \hat{Y}\) contributes \(-1\)
\(\displaystyle = -\frac{Y}{\hat{Y}} + \frac{1 - Y}{1 - \hat{Y}} = \frac{-Y(1 - \hat{Y}) + (1 - Y)\hat{Y}}{\hat{Y}(1 - \hat{Y})}\)
common denominator
\(\displaystyle = \frac{-Y + Y\hat{Y} + \hat{Y} - Y\hat{Y}}{\hat{Y}(1 - \hat{Y})} = \color{#3274B5}{\frac{\hat{Y} - Y}{\hat{Y}(1 - \hat{Y})}}\)
expand; the \(Y\hat{Y}\) terms cancel

Derivative of the Log Loss (2/3)

Part 2: \(\dfrac{\partial \hat{Y}}{\partial \mathbf{w}}\), where \(\hat{Y} = \sigma(\mathbf{w}^T \cdot \mathbf{x})\)

We need the derivative of the sigmoid:

\[ \frac{\partial \sigma(z)}{\partial z} = \sigma(z)\big(1 - \sigma(z)\big) \]

So, by the chain rule:

\[ \frac{\partial \hat{Y}}{\partial \mathbf{w}} = \frac{\partial \sigma(\mathbf{w}^T \cdot \mathbf{x})}{\partial \mathbf{w}} = \sigma(\mathbf{w}^T \cdot \mathbf{x})\big(1 - \sigma(\mathbf{w}^T \cdot \mathbf{x})\big) \cdot \frac{\partial (\mathbf{w}^T \cdot \mathbf{x})}{\partial \mathbf{w}} \]
\[ = \color{#A62B17}{\hat{Y}(1 - \hat{Y}) \cdot \mathbf{x}} \]

Derivative of the Log Loss (3/3)

Part 3: combine them

\[ \frac{\partial LL_n}{\partial \mathbf{w}} = \color{#3274B5}{\frac{\partial LL_n}{\partial \hat{Y}}} \cdot \color{#A62B17}{\frac{\partial \hat{Y}}{\partial \mathbf{w}}} \]
\[ = \color{#3274B5}{\frac{\hat{Y} - Y}{\hat{Y}(1 - \hat{Y})}} \cdot \color{#A62B17}{\hat{Y}(1 - \hat{Y}) \cdot \mathbf{x}} \]
\[ = (\hat{Y} - Y) \cdot \mathbf{x} = -(Y - \hat{Y}) \cdot \mathbf{x} = -\delta \cdot \mathbf{x}, \quad \text{where } \delta = Y - \hat{Y} \]
The sigmoid derivative \(\hat{Y}(1 - \hat{Y})\) cancels the denominator from the log derivative. This is why the log-loss works so well with the sigmoid.

\(l^{(log)}\): Back to the Familiar Update

  • The gradient with respect to \(\mathbf{w}\) is \[ \nabla_{\mathbf{w}} LL(\mathbf{w}) = -\sum_n \delta \cdot \mathbf{x}_n, \quad \text{where } \delta = Y(\mathbf{x}_n) - \hat{Y}(\mathbf{x}_n) \] which brings us back to the familiar weight update: \[ \mathbf{w} \leftarrow \mathbf{w} + \eta \cdot \delta \cdot \mathbf{x}_n \]

Why Are the Weights So Different?

  • Linear regression weights are small: \(\mathbf{w}^T \cdot \mathbf{x}\) is fitted directly to the 0/1 targets, so they stay on the scale of the targets
  • Logistic regression weights are large:
    • larger weights → steeper sigmoid → more confident predictions
    • with no regularisation, the log-loss keeps falling as the weights grow, while the training points stay on the correct side. Our data is almost separable, so the weights grow until the solver stops
    • so their size reflects when the solver stopped, not how “important” a feature is
  • Regularisation keeps them finite (scikit-learn’s default is \(C = 1\))

Summary

  • Linear regression fits \(\hat{Y} = \mathbf{w}^T \cdot \mathbf{x}\) by minimising the SSE
    • gradient descent: \(\mathbf{w} \leftarrow \mathbf{w} + \eta \cdot \delta \cdot \mathbf{x}_n\); too small an \(\eta\) is slow, too large oscillates or diverges
    • closed form: \(\mathbf{w} = (X^T X)^{-1} X^T Y\), exact but \(\mathcal{O}(D^3 + D^2N)\); gradient descent \(\mathcal{O}(KND)\) wins for large \(D\)
  • Regression outputs are not probabilities. For classes, use logistic regression: \(\hat{Y} = \sigma(\mathbf{w}^T \cdot \mathbf{x})\)
    • with the sigmoid, the log-loss gives the simple gradient \(-\delta \cdot \mathbf{x}\); the squared loss adds \(\hat{Y}(1 - \hat{Y})\), which vanishes when the model is confidently wrong
    • without regularisation, the weights on (almost) separable data keep growing
